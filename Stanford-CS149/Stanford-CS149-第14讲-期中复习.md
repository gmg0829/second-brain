# Stanford CS149 并行计算 第十四讲：期中复习

## 概述

本讲为课程期中复习，涵盖前几周的核心内容。

## 课程主线

### 1. 多核架构理解
-  Lectures 1-3 涉及的多核架构是重要考点
-  确保真正理解其工作原理

### 2. 并行程序优化策略
- **工作负载均衡**：识别程序中的负载不均衡问题
- **缓存性能优化**：通过调整循环顺序等手段改善缓存命中率

### 3. GPU 架构基础
- GPU 可视为扩展版多核架构，原理相通
- CUDA 编程模型：线程块（Thread Blocks）与线程的组织方式
- 第三次编程 Assignment 后应有深入理解

### 4. 深度神经网络
- **缓存局部性**：blocking 策略的重要性
- 专用硬件概念（期末再深入）

## 复习建议

- 多核架构原理务必理解透彻
- 能识别常见的负载不均衡和缓存性能问题
- 掌握 CUDA 编程模型基本概念
