## 核心观点

### 一、稳定币是什么？

稳定币（Stablecoin）是一种建立在区块链上的加密货币，其价值锚定美元等法币，以1:1比例可赎回。

**核心机制**：
- Tether（泰达）收取你1美元 → 在区块链上创造1枚USDT
- 市场价 > 1美元 → 找Tether买入，市场抛售 → 价格压回1美元
- 市场价 < 1美元 → 市场上买入 → 卖给Tether → 价格拉回1美元
- **100%储备担保**：每发行1枚稳定币，需至少1美元储备（通常是短期国债/隔夜逆回购）

**两大发行巨头**：
| 公司 | 发行量 | 2024年净利润 |
|------|--------|-------------|
| Tether（USDT） | ~1,436.8亿美元 | 130亿美元 |
| Circle（USDC） | 严重依附交易所 | 16.8亿美元（利息收入） |

> "你甚至都不用去理解什么区块链加密货币——它其实有点像一个游戏公司发行了自己的游戏币/Q币，然后通过抵押资产来给这个游戏币的价值担保。"

**讽刺现实**：虽然区块链理念是"去中心化"，但主流稳定币仍然依赖一个机构中心化发行的模式。

### 二、稳定币的三大优势

| 优势 | 对比传统跨境支付 |
|------|----------------|
| **便捷** | 无跨境、无汇率转换、无需银行对接、无需SWIFT，分分钟到账，手续费极低 |
| **私密** | 交易对手只知道你的区块链地址（如"九亿少女的梦"），不知道你是隔壁老王 |
| **稳定** | 锚定美元，无价格波动 |

> "稳定币弥补了比特币最大的短板——又便捷、又私密、又稳定，这不就是理想的交易货币吗？"

### 三、市场规模与现状

| 指标 | 数据 |
|------|------|
| 全球稳定币总市值 | 超过 **2,500亿美元**（5年翻20多倍） |
| 2024年交易量 | **27.6万亿美元** |
| vs Visa+Mastercard | 稳定币交易量已超过两者年度支付总和 |
| vs 比特币市值 | 只有比特币的约1/8，但**交易量已超过比特币** |

**三大应用场景**：
1. **跨境支付**：1年半前几乎为零，现已达~500亿美元/月，增速20-30%/月（全球跨境支付市场天花板~200万亿美元/年）
2. **高通胀国家**：阿根廷、尼日利亚、巴西、土耳其民众将稳定币当数字美元用——绕过外汇管制，甚至可合法付房租
3. **灰色/地下交易**：稳定币弥补了比特币价格波动缺点，成为黑市首选

### 四、各国稳定币立法图谱

#### 1. 积极开放型：香港、新加坡、阿联酋

**香港**（最激进）：
- 2025年5月推出《稳定币条例草案》（8月1日生效），采取"**沙盒**"隔离监管试点
- 首批三家牌照：京东币链、原币创新、渣打银行联盟（蚂蚁集团虎视眈眈）
- 重点方向：**港元稳定币 + 离岸人民币稳定币试点**
- 6月22日启动**跨境支付通**：内地与香港点对点直连，用分布式账本技术与稳定币兼容

**阿联酋**：最开放——"只要不禁止你都可以试试"，税收几乎为零，币圈公司蜂拥

**新加坡**：2024年6月《金融服务和市场法案》正式生效，必须持牌才能向海外客户提供数字代币服务

---

#### 2. 谨慎包容型：美国、欧盟、韩国

**美国《GENIUS法案》核心规定**：
- 资质要求：发行稳定币企业须注册获牌
- 储备资产要求：**100%高质量流动性资产**（短期国债、隔夜逆回购），不可再抵押
- 偿付优先级：**破产时储备先赔付稳定币持有者**
- 风控/信披/反洗钱要求

**欧盟MiCA法案**：比美国更保守
- 禁止收取代币赎回费
- 禁止稳定币支付利息
- 严格限制日交易量
- 理由：对金融稳定、支付系统平稳运行、货币主权构成风险

**韩国**：2022年Luna币崩盘（韩国投资者损失40亿美元+）后倾向严管，但新总统李在明态度友好，允许韩元稳定币

### 五、大国博弈的核心逻辑

稳定币革命 = **金融脱媒**（跳过银行、支付公司等金融中介）

#### 美国想达成的三个目标：

| 目标 | 具体动作 |
|------|---------|
| 1. 强化美元地位 | 稳定币99%是美元稳定币——推广稳定币 = 推广美元；"土耳其、尼日利亚、阿根廷全用美元稳定币交易 = 完全美元化" |
| 2. 增加美债需求 | Tether 2024年净买入美债331亿美元（全球第七大买家）；预计2028年稳定币规模翻8倍，对短债需求超1万亿美元 |
| 3. 抢占加密世界地位 | 特朗普：签署《加强美国数字金融技术领导地位》行政令；禁止数字美元；把自己包装成"加密总统" |

#### 特朗普家族发行的币：
- $TRUMP币（80%由特朗普公司控制），一度总市值600亿美元，现跌至个位数
- USD1稳定币（阿布扎比投资局投入20亿美元后规模从亿级飙到22亿美元）

#### 各方目的不同，但都在推动市场：
- 美国 → 强化美元 + 卖美债 + 抢占加密地位
- 特朗普个人 → 获利
- 币圈公司 → 合规 + 赚钱 + 上市信用背书
- 其他国家 → 不错过这班车，争取本国/本币话语权

### 六、未来趋势：RWA（Real World Assets，真实世界资产代币化）

> "各国想要推动的不光是稳定币，而是'代币化'——把现实世界的资产映射到区块链上。"

**案例**：
- 贝莱德（全球最大资管公司）2025年3月在链上发行美元货币基金 **BUIDL**，规模已达29亿美元
- 蚂蚁集团在香港Ensemble沙盒项目：充电桩RWA、光伏RWA、换电站RWA

稳定币 = 最简单的RWA。进阶形态：债券代币化、知识产权上链、房地产映射。

---

### 七、对现有金融体系的冲击

稳定币崛起 = **"金融脱媒"** = 跳过金融中介

| 受损方 | 影响 |
|--------|------|
| 银行 | 流失灵活资金、放贷能力受损；摩根大通已悄悄发行摩根币 |
| 支付公司（Visa/Mastercard） | 稳定币交易量已超过两者总和 |
| 央行/货币政策的传导 | 银行与经济体的联结减弱 → 货币政策效果降低 |

**监管悖论**：
- 监管要求100%储备 → 钱回流银行体系 → 理论上银行损失不大
- 但银行会丧失主动权、金融创新能力和与经济的联结深度
