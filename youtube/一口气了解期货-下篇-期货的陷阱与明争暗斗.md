## 一、"327国债事件"——中国期货市场的血腥一战（1995年）

### 1.1 背景

**代号"327"的国债期货合约** + **保值贴补政策的不确定性**

> 财政部对国债有保值贴补政策，但具体贴补多少是财政部定的——市场对此有很大分歧。

| 阵营 | 多头（中经开） | 空头（万国证券 + 辽国发） |
|------|---------------|------------------------|
| **判断** | 贴补会更高 | 贴补会降下来 |
| **策略** | 做多 | 做空 |
| **持仓量** | — | 一度高达140万口 |

### 1.2 事件时间线

| 日期 | 事件 |
|------|------|
| **2月10日** | 财政部公布3月保值贴补率——反而创了新高。对万国不利。 |
| **万国的选择** | 不是割肉离场，而是**加倍下注**——从40万口加到80万口 |
| **2月22日晚** | 财政部又出利好：第一期国债利率14%，实行保值贴补 |
| **2月23日** | 开盘跳到149.5，多头一路推高到150以上 |

### 1.3 "疯狂8分钟"——2月23日最后决战

**万国的困境：**
- 价格明显要涨，但作为空头必须把价格压下来才能平仓
- 只能靠增加空头头寸把价格打下来
- 盟友辽国发临阵倒戈，反手做多50万口
- 价格瞬间跳到151.98

**16:22 - 16:30，"疯狂8分钟"：**

| 操作 | 结果 |
|------|------|
| 万国集中全部资金疯狂做空 | 先用50万口把价格从151.3压到150 |
| 继续加大头寸 | 价格打破150、149、148 |
| **最后一笔卖单** | 估算超过2,000万口（成交超过1,000万口） |
| **市值** | 相当于2,000亿面值、3,000亿的国债——超过327国债名义发行量的9倍 |

**结果：** 万国凭借强大做空力量把价格生生从151.3打到了147.4——**当天整个327国债期货市场成交高达8,500亿元，相当于当年全国GDP的14%。**

### 1.4 结局

| 事件 | 结果 |
|------|------|
| **上交所紧急宣布** | 那8分钟的交易全部作废，收盘价调回151.3 |
| **万国** | 从刚刚的盈利瞬间变成亏损14亿 |
| **融资援助** | 上交所等机构融资15亿给万国，但万国还是濒临破产，与申银证券合并 |
| **管金生（万国总裁）** | 被判17年有期徒刑 |
| **辽国发** | 操纵市场和金融诈骗被查处，负责人外逃 |
| **国债期货** | 被叫停了近20年，直到2013年才重启 |

## 二、2022年镍市逼空——青山控股危机

### 2.1 背景

| 角色 | 说明 |
|------|------|
| **青山控股** | 全球最大不锈钢企业 + 全球最大镍生产商，年产占全球1/4 |
| **镍期货市场** | 相对较小的市场，青山具有统治地位 |
| **2022年初** | 俄乌战争爆发，俄罗斯被欧美经济制裁——俄镍无法交割 |

**青山的问题：**
- 持有大量镍期货空头（15-20万吨）
- 青山生产的镍是铁镍和高冰镍，纯度不够——**无法直接用于期货交割**
- 俄罗斯被制裁 + 镍库存极低（不到8万吨，往年一半不到）
- 而镍期货市场规模超过110万吨，是现货市场的**15倍**

### 2.2 逼空过程

| 时间 | 价格 | 事件 |
|------|------|------|
| **2022年3月初** | ~2.4万美元/吨 | 投机资本开始做多镍期货逼空 |
| **3月7日晚** | 超过5万美元/吨 | 翻了一倍 |
| **3月8日凌晨** | 超过10万美元/吨 | 再翻一倍 |

> 青山面临损失高达**100亿美元**

### 2.3 LME紧急干预

**3月8日早上8:15，伦敦金属交易所（LME）宣布：**
- 紧急停市
- 宣布当天零点后的所有期货交易（大约9,000笔）**全部作废**

**逼空资本是谁？** Elliott、AQR、Jane Street——华尔街顶级对冲基金

**后续：**
- 多头纷纷起诉LME
- 英国罚了LME清算所920万英镑
- 青山与券商债权人达成静默协议，**亏损约10亿美元**（算侥幸逃生）
- 摩根大通也因此笔交易**损失约1.2亿美元**

## 三、2020年"负油价"——史诗级崩盘

### 3.1 背景

| 因素 | 说明 |
|------|------|
| **疫情爆发** | 全球原油需求崩溃 |
| **OPEC+谈判破裂** | 沙特和俄罗斯陷入价格战 |
| **油价** | 从年初60美元一度跌到20美元 |
| **抄底资金** | 大量亚洲散户想抄底油价 |

**"纸原油"产品：**
- 散户不会直接交易原油期货
- 金融机构（如中国银行"原油宝"）提供"纸原油"理财产品
- 银行在CME（芝加哥商品交易所）真的交易WTI原油期货，对冲风险

### 3.2 为什么会跌到负数？

**原因一：储油库严重不足**
> 原油交割地点是俄克拉荷马州库欣镇——全球炼油中心
> 当时库欣储量已占用超过80%，租金成本极高

**原因二：散户太多，宁可倒贴也不愿真收油**
> 很多纸原油产品会提前几天"移仓换月"（Roll）
> 但中国银行不知何故**没有提前移仓**

### 3.3 2020年4月20日——黑色星期一

**当天最后两天的状况：**
- 市场还有13万手期货没平仓
- 其中**2/3是散户持有的多头**（通过理财产品）

**"TAS单"（结算价订单）的致命作用：**
> "按今天收盘的价格给我全卖了"——不管价格多少都要卖
> 超过一半的头寸都是TAS订单，必须在收盘前卖出

**最终博弈：**
> 多空双方都必须在收盘前平仓——争夺收盘前那几分钟的价格
> 空头：把价格打越低越好
> 多头（散户）：不管多低都得卖

**收盘前最后30分钟：**

| 时间 | 油价 |
|------|------|
| 14:26 | -15美元 |
| 14:28 | -20美元 |
| 14:29 | -30美元 |
| 14:30（收盘） | **-37.63美元**（最终均价） |

> **最后三分钟——油价从0美元一口气跌到了-40美元**

### 3.4 结局

| 损失方 | 情况 |
|--------|------|
| **被迫平仓的多头（散户）** | 仅这一天亏损超过**40亿美元** |
| **中国银行** | 承担穿仓损失，补偿客户20%本金，超过**60亿人民币** |
| **赢家** | 成功逼仓的空头们 |

## 四、期货实物交割的小故事

## 五、期货市场的真正意义——风险交易而非赌博

### 5.1 零和博弈 ≠ 赌博

> 每一笔合约多空双方完全对称——你赚我就亏，你亏我就赚。
>
> 但整个期货市场不是赌博，而是**透过风险交易来优化全球的风险管理**。

### 5.2 市场的风险分工

**举例：**
- **实体经济参与者**：需要对冲业务风险（农民对冲粮价、航空公司对冲油价）
- **杠杆基金/对冲基金**：发现定价不合理就冲进去套利，同时把期货价格推向合理位置
- **国债市场**：保险公司/养老基金有投资需求但资本限制导致买国债成本高 → 选择做多国债期货（成本低）
- **国债现货持有人**（如共同基金）：愿意承担利率风险换取收益

> 期货市场 = 巨大的风险交易场所
> 透过期货优化风险分工

### 5.3 健康市场需要严格监管

> 交通工具越先进，交规限制就得越严。
>
> 刚才说的那些把对方"干死"的逼仓行为，其实是各大交易所试图避免的"车祸"。

## 六、核心概念总结

### 逼仓（B corners）的两种类型

| 类型 | 机制 | 案例 |
|------|------|------|
| **逼空** | 多头做局，持有远超市场实物供应的多头期货，空头无法交割被迫平仓 | 青山控股镍逼空、327国债事件 |
| **逼多** | 罕见，空头做局把价格打到极低，持有大量的空头期货逼迫多头无法承受损失 | 2020年负油价 |

### 高杠杆 + 保证金制度 = 死亡螺旋

| 案例 | 杠杆倍数 | 后果 |
|------|----------|------|
| 327国债 | ~33倍 | 8分钟成交8,500亿国债期货 |
| 青山镍逼空 | ~10倍 | 镍价2天内从2万涨到10万，青山面临100亿损失 |
| 负油价 | — | 1天40亿美元蒸发 |

### 期货合约数量为什么可以超过现货数量？

> 期货合约数量由市场供需决定，完全不像股票是定死的。
>
> 只要买卖双方价格匹配，一份新合约就产生；双方都想平仓，一份合约就消失。
>
> 到期时只有100杯奶茶实物，但理论上期货市场可以是无限大的。
