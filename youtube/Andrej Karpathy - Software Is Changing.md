## 简介 / Introduction

Andrej Karpathy 探讨 AI 如何改变软件开发的方式，以及未来的编程将是什么样子。

---

## 核心观点 / Core Insights

### 1. 软件开发的演变 / Evolution of Software Development

**传统开发：**
- 人类编写代码
- 明确的指令
- 固定的逻辑

**AI 时代开发：**
- AI 辅助编程
- 自然语言描述需求
- 动态生成代码

### 2. 编程的本质变化 / Programming is Changing

**从代码"到"设计"写系统"：**
- 关注点从具体实现转向架构设计
- AI 处理大量编码工作
- 人类专注于创造性和策略性决策

### 3. 新技能的重要性 / New Essential Skills

| 技能 | 描述 |
|------|------|
| 提示工程 | 与 AI 有效沟通 |
| 系统设计 | 设计 AI 集成架构 |
| 批判性思维 | 评估 AI 输出质量 |

### 4. AI 原生应用 / AI-Native Applications

- 软件将更加智能和自适应
- 用户界面更加自然
- 个性化程度更高
