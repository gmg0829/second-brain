## 核心观点：六个"反传统"创业心法

John Mullins 称之为"与常规智慧相反"的六种思维模式——它们打破了大公司的"最佳实践"，却成就了众多传奇企业。

---

### 心法一："Yes, we can."（永远说"可以"）

| 项目 | 内容 |
|------|------|
| 典型案例 | Arnold Correia（巴西）——Atmo Digital |
| 核心逻辑 | 当客户提出超出你核心能力的需求时，说"可以"，然后想办法做到 |
| 实践 | Arnold原本做活动管理，两次重新定义业务。每次客户提出新需求（卫星传输、电视屏幕广告），他都说"可以"——即便他完全不懂卫星技术。最终**四次重新定义自己的业务** |

> **常规智慧**：专注核心能力（core competencies），做你最擅长的事，不要分散精力。

### 心法二："Problem-first, not product-first"（先找问题，而非先有产品）

| 项目 | 内容 |
|------|------|
| 典型案例 | Jonathan Thorne ——外科手术钳 |
| 核心逻辑 | 创业者的焦点不是产品，而是**要解决的问题** |
| 实践 | 他发明了一种不粘人体组织的新型银镍合金手术钳。最初瞄准整形外科医生——但业务增长缓慢。他重新思考："哪个细分科室的问题更大？"答案是**神经外科**——大脑和脊椎手术中，如果钳子粘住其他组织，后果更严重。他聚焦神经外科，最终公司以高价卖给Stryker |

> **常规智慧**：先有技术/产品，再去找市场。
> **反传统**：先找到真实且痛苦的问题，再看你的技术能否解决。

### 心法三："Think narrow, not broad"（从小处切入，而非大市场）

| 项目 | 内容 |
|------|------|
| 典型案例 | Philip Knight + Bill Bowerman —— Nike |
| 核心逻辑 | 不要一开始就想服务大众市场——**先征服一个高度具体的小群体** |
| 实践 | Nike起步时，聚焦**长跑运动员**这个极窄的群体。他们分析：跑步鞋在当时是为短跑设计的（平滑跑道），但长跑运动员在土路、碎石路上跑，会扭伤脚踝、得胫骨夹板。Knight和Bowerman为这个窄众人群设计了更好的鞋：更好的侧向稳定性、更宽的鞋床、更多缓冲、更轻。**技能建立后**，再扩展到网球（约翰·麦肯罗）、篮球（迈克尔·乔丹）——NIKE由此诞生 |

> **常规智慧**：瞄准大市场，才能做大。
> **反传统**：做小池塘里的大鱼比做大池塘里的小鱼容易得多。

### 心法四："Ask for the cash, and ride the float"（收现金，驾驭浮力）

| 项目 | 内容 |
|------|------|
| 典型案例 | Elon Musk + Tesla |
| 核心逻辑 | 用**预售/定金**创造现金流，在花自己的钱之前就拿到现金 |
| 实践 | **第一批Roadster**：100辆，每辆$10万，**立即现金交付**——$1000万现金进账，**在第一辆车还没造出来之前**。**Model 3**：数十万消费者支付$1000定金，**5亿美元现金**在工程开始前就已在账上 |

> **常规智慧**：做好产品，上市，再收钱。
> **反传统**：你的商业模式本身就是融资工具——用客户的现金来建设你的业务。

### 心法五："Beg, borrow, but please don't steal"（能讨就讨，能借就借，但绝不偷）

| 项目 | 内容 |
|------|------|
| 典型案例 | Tristram + Rebecca Mayhew —— Go Ape（英国树顶冒险公司） |
| 核心逻辑 | **资产轻型化**——不要买你要用的资源，而是**借**或**谈判**来获取使用权 |
| 实践 | Go Ape想建树顶探险场地。他们**不需要买树**（英国森林委员会有），他们谈判获取使用权：先建5个示范点，成功后获得**25年独家经营权**。他们借用了树木、厕所、停车场——**所有重资产都是别人的**，他们只负责把设备套在树上。今天Go Ape在英国有30多个站点，并进入了美国 |

> **常规智慧**：要做事，先融资，先购置资产。
> **反传统**：你能租用的，就不要买。核心能力是**整合资源**，而不是拥有资源。

### 心法六："Don't ask permission"（不要请求许可）

| 项目 | 内容 |
|------|------|
| 典型案例 | Travis Kalanick + Garrett Camp —— Uber |
| 核心逻辑 | 当监管法规还没有考虑数字时代的可能性时，**先做再说** |
| 实践 | Uber创始旧金山：如果先去问监管机构"我能用APP叫没有执照的车吗？"答案一定是"不行"。他们没有请求许可，直接上线服务。用**先斩后奏**的方式创造了新范式 |

> **警告**：Uber的旅程中有很多不道德、甚至可能违法的行为（Mullins明确表示不认同）。但**原则**是：在监管灰色地带，创业者不会等着说"可以吗？"——他们直接做。

## 深度分析

### 1. 六种思维模式的共同逻辑

这六种思维模式有一个共同主线：**打破大公司规则的枷锁**。

| 常规智慧 | 反传统的创业逻辑 |
|----------|-----------------|
| 专注核心能力 | 客户要什么，就说"可以" |
| 先有产品，再找市场 | 先找痛点，再匹配解决方案 |
| 瞄准大市场 | 从极窄群体切入 |
| 用自己的钱或融资 | 用客户的钱作为现金流来源 |
| 拥有资产 | 借用/租用资产 |
| 先获得许可再行动 | 先做，在监管追上来之前建立事实 |

### 2. 为什么这些思维是"可学的"？

Mullins在演讲最后提出了四个问题：

1. **你已经拥有了哪些思维模式？** ——自我诊断
2. **哪些是可以学会的？** ——他认为是全部都可以
3. **你能教会你的同事吗？** ——用这些框架帮助团队
4. **你当前面临的挑战中，哪一个可以用这些思维突破？** ——学以致用

### 3. 创业者最大的风险：不是失败，是"等许可"

Uber的案例揭示了一个深刻洞察：
- 大公司需要合规，创业者则需要**在监管框架意识到问题之前就创造事实**
- 这既是Uber成功的核心，也是它一路上诸多争议的根源
- **"不要请求许可"不等于"违法"**——边界在于：监管灰色地带 vs 明确违法

### 4. 对创业者的实操启示

| 思维 | 具体行动 |
|------|----------|
| Yes, we can | 客户提出任何需求，先说"可以"，再想怎么做 |
| Problem-first | 在写代码/做产品之前，先花大量时间找到真正的痛点 |
| Think narrow | 不要做"面向所有人的东西"——找到一个细分群体，做透 |
| Cash first | 设计你的商业模式，让你在花自己的钱之前就收到现金 |
| Borrow assets | 盘点你业务中哪些重资产可以借用或租用，而非购买 |
| Ask forgiveness, not permission | 如果监管没有明确禁止，就先做再说——但要清楚边界 |
