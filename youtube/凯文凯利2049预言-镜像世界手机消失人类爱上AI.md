## 一、关于新书与写作方法论

### 1.1 为什么要写这本书？

> **这不是预测（Predictions），而是场景（Scenarios）。**
>
> "我想象的是25年后一个我们真正想要生活在其中的世界——一个乐观的世界，在这个世界里一切运转良好。"

**方法论：倒推法**

> "从25年后的未来倒推——如果有人从未来回来说'AI成功了，大家都喜欢它'，那么问题就变成了：我们要怎么走到那一步？"

### 1.2 为什么大多数科幻都是灾难片？

> "科幻小说和电影都在探索未来的阴暗面。但技术的本质就是双刃剑——这是不可避免的。"

**K.K.的策略：**
- 研究负面风险是真实存在的，但**不需要由他来做**
- "成千上万的人都在写负面的东西，我不需要"
- 他的工作是说正面的事——因为很少有人在说

## 二、教育：未来孩子需要什么？

### 2.1 K.K.给年轻父母的建议

> K.K.两个月前刚有了儿子Benjamin——无论Benjamin 25年后做什么工作，那个工作今天都不存在。

**核心技能：学会学习（Learning How to Learn）**

| 技能 | 说明 |
|------|------|
| **学会学习** | 这是毕业时最重要的技能——懂得如何优化自己的学习 |
| **学会提问** | AI会给你所有答案——但提问才是真正有价值的，提问比答案更需要有创造力，AI也难以做好 |
| **按自己节奏学习** | AI可以让学生按自己的进度来 |
| **保持热情** | 不要被经济学左右——做你热爱的事，做你擅长的事 |

### 2.2 选什么专业？

> "成为某件事的专家——做什么不重要，可以是编织、运动，任何事。"
>
> "成为某个领域的专家，这会带你走向你从未预期的地方。"
>
> "不要觉得你必须成为医生或律师——去真正跟医生或律师待一周，看看那是不是你想要的生活。"

## 三、媒体行业：记者会被取代吗？

### 3.1 答案是：需要更多记者

> **"25年后，我们可能仍然需要记者——甚至可能需要更多。"**

**AI做不到的事——承担责任：**

> "AI可以完成研究工作，可以阅读论文，可以联系教授提问——但谁来为输出的结果负责？"
>
> "AI没有责任感，没有问责制。至少在25年内，记者的工作就是监督AI做的研究，并为结果负责——这是人类的工作。"
>
> "你雇一个人，如果他们没做好，是他们的责任，他们得负责做好。AI没有这种责任感。"

### 3.2 下一个平台是什么？

**K.K.看好的方向：**

| 媒体形式 | 说明 |
|----------|------|
| **YouTube** | "被严重低估了，会变得越来越强大" |
| **体验式新闻** | 戴上眼镜，你就可以站在事件现场——不是旁观报道，而是身临其境 |
| **个人创作** | Substack等 Newsletter 形式会继续存在 |

**关于媒体创业：**
> "越成功、越大的媒体，转型越难——因为有太多东西要保护，太多人要养活。"
>
> "创业公司的优势：失败了也只是几个人受影响。你们只需要不断尝试——前10次大概率都会失败。"

## 四、镜像世界（Mirror World）与智能眼镜

### 4.1 什么是镜像世界？——四个层次

| 层次 | 描述 |
|------|------|
| **第一层** | 虚拟现实——戴上眼镜，进入三维的、与现实一样逼真的想象世界 |
| **第二层** | 数字孪生——你的虚拟化身，在家通过摄像头就能看到，可以做培训、手术、教育等各种事 |
| **第三层** | 自动驾驶汽车看到的世界——不只是物理世界，还有叠加的交通信号、地图、限速等信息层 |
| **第四层** | AI实时扫描、理解整个物理世界——当你戴上眼镜走路，它会实时映射："这是楼梯，门在那里，我可以从那里上去" |

> **"这个世界之所以可能，是因为AI变得非常便宜、快速，而且必须融合真实世界。"**
>
> **"无论我们做什么，一旦人们戴上眼镜，这个镜像世界就必然会出现——这是AI扫描理解整个世界的自然结果。"**

### 4.2 智能眼镜竞争：谁会赢？

**K.K.的观点：**
> "我不知道谁会赢。但如果有10个重大技术突破需要同时解决——甚至苹果都无法做到这一点。"

**挑战包括：**
- 续航（不想被线缆束缚）
- 视场角
- 触摸/交互方式
- 重量/舒适度
- AI芯片必须内置在眼镜里

**时间线：** "我们离真正能被大众接受的智能眼镜还有**5-10年甚至更久**。"

### 4.3 中国有机会吗？

> **"我可能会赌中国公司赢，而不是苹果。"**

原因：
1. 硬件供应链优势
2. 材料科学的know-how
3. 愿意做半成品、在半途找到应用场景的意愿

## 五、人形机器人：进入家庭？

### 5.1 K.K.的冷静判断

> "人形机器人进入家庭，可能**不是25年内的事**。"

**时间线对比：**

| 机器人类型 | 时间线 | 说明 |
|------------|--------|------|
| **仓库机器人** | 更早出现 | 场景更受限制，更容易商业化 |
| **餐厅机器人** | 会看到 | 场景相对简单 |
| **家庭机器人** | 25年内不会普及 | "可能不会比现在好多少，但会更便宜——比如1000美元" |

**原因——手的挑战：**
> "手是人体最了不起的部分之一——同时能用它缝针和举起100磅重物。这种触觉、力量和精细控制的结合，对机器来说非常非常难。"
>
> "就像VR一样——40年后VR并没有变得更好，只是便宜了几百万倍。机器人也会走类似的路径。"

## 六、驾驶：还需要考驾照吗？

### 6.1 两种趋势

| 趋势 | 说明 |
|------|------|
| **获取驾照可能变难** | 当你周围都是AI驾驶汽车时，你的驾驶技能必须更好 |
| **驾驶区域会缩小** | 某些城市核心区可能不允许人类驾驶——因为AI控制交通更高效 |
| **驾驶变成稀有技能** | 类似飞机驾驶执照——变得罕见，需要更高质量培训 |

> "25年后，开车可能不再是必需品——但如果你真的想开，它会变成一种像开飞机一样的专长。"

---

## 七、火星：会有城市吗？

> **"我认为火星永远不会有城市。"**

**理由：**

| 论点 | 说明 |
|------|------|
| **难度差** | "在海底建城市都比在火星建城市容易100万倍——但我们连海底城市都没建" |
| **没有经济理由** | 去月球/火星主要是科研，间接经济收益来自技术溢出（如卫星技术） |
| **火星的价值** | 小行星采矿等经济价值在近地空间就能实现 |
| **人类不必亲自去** | "我们可以派出AI、摄像头、虚拟现实——不需要派人类肉体去太空" |

> "火星上会有研究站——但那只会是研究站，不会是城市。最多就像南极研究站那样。"
>
> "这会告诉我们怎么在封闭环境生活两年——但谁想在那底下待两年？"

## 八、长寿与生命科学

### 8.1 K.K.的个人态度

> **"我不想死，但我不害怕它。"**

**K.K.对延寿的看法：**

| 立场 | 说明 |
|------|------|
| **支持** | 延长健康年龄——"这是真正的好主意" |
| **怀疑** | 延长绝对寿命——"进展会非常非常缓慢" |
| **判断** | 即使是最极端的延寿实验，人类寿命延长也非常有限 |

### 8.2 AI对医疗的影响

**可能的突破（25年内）：**
- 泛病毒疫苗
- 癌症疫苗
- 人类活得更长、更健康

### 8.3 人口萎缩的挑战

> "25年后，地球和中国的人口都会萎缩。老龄化+少子化将成为挑战。"
>
> **"这对创新来说是挑战——当你身边都是不想冒险的老人和创新者越来越少时。"**
>
> "解决方案之一是AI——AI也会消费，不只是生产"

**K.K.的人口预测：**
> "WHO和联合国说人口萎缩要到2070年才明显——但我认为**2046年**就会开始。"

## 九、BCI（脑机接口）

### 9.1 进展比K.K.预期的快

> "这个领域发展得比我想象的快——100年内我们可能会有读心的东西。但现在有很多实验和创业公司在做非侵入式的脑机接口。"

### 9.2 25年内的可能性

| 类型 | 说明 |
|------|------|
| **侵入式** | 只适用于有医疗需求的群体（截瘫患者等）——普通人不会往脑子里钻东西 |
| **非侵入式** | 戴个帽子在头上，提取信号，控制设备 |

**可能的应用场景：**
- 游戏玩家（减少反应延迟）
- 艺术家（用意念创作）
- 某些形式的"想象创作"

> "说实话，我们不太确定非侵入式脑机接口具体怎么用——可能没有我们想象的那么酷。"

## 十、硅谷的未来

> **"现有的科技巨头会倒下，新名字会出现——这毫无疑问，就像OpenAI和Anthropic的出现一样。"**

**更有趣的问题：**

> "真正的问题是：硅谷本身的运作方式会改变吗？VC模式会变吗？创业的路径会变吗？"
>
> "AI可能会让创业变得更容易——可能会出现Kickstarter版的VC。"
>
> "深圳在制造业和材料方面的深度积累，让它在中国的角色不会改变——就像硅谷在全球的角色一样。"

**房地产问题：**
> "住房问题可能是真正影响硅谷未来的因素——如果人们负担不起在那里创业，那就真的成了问题。"
