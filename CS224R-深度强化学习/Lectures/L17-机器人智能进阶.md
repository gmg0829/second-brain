## 强化学习与模仿学习在机器人领域的对比

### 成功的强化学习系统的关键特征

对比**实际有效的**模仿学习 vs **实际有效的**强化学习：

| 特征维度 | 模仿学习 (IL) | 强化学习 (RL) |
|---------|-------------|--------------|
| **数据来源** | 离线数据（人类演示） | 在线采集（当前策略生成） |
| **策略更新** | 使用全部历史数据训练 | 仅使用当前策略采集的数据 |
| **输出形式** | 通才模型（多任务统一） | 专才模型 / 或对预训练模型的特化 |
| **典型成果** | 游戏AI、LLM推理、机器人灵巧性 | AlphaGo、LLM推理能力突破、机器人敏捷性 |

**强化学习成功的两个核心要素：**

1. **Well-specified Rewards（明确定义的奖励）**
   - AlphaGo：胜/负二值奖励（游戏规则明确）
   - LLM推理：基于规则的奖励函数（可自动化、大规模）

2. **大规模运行策略的能力**
   - 仿真环境：可编程计算奖励 + 可扩展计算
   - 物理世界：需要Sim2Real迁移

```
强化学习成功公式：
好的奖励定义 + 可扩展的数据收集 = 突破性成果
```

## Sim2Real的核心挑战与解决方案

### 问题陈述

仿真环境（Simulation）≠ 真实物理世界（Real World）

| 仿真优势 | 真实世界挑战 |
|---------|-------------|
| 可精确计算奖励（完整状态已知） | 状态信息不完整，需传感器 |
| 可快速评估策略（数字化） | 物理实验耗时长、成本高 |
| 物理规律可精确建模 | 摩擦、柔性、材质差异难以精确建模 |

### 解决方案框架

**核心思路：让在仿真中训练的策略能零样本（Zero-shot）部署到真实机器人**

## Rapid Motor Adaptation (RMA)：盲眼四足机器人

### 系统架构

**问题**：机器人在未知地形上行走，地形参数（摩擦系数、质量、地面硬度等）未知。

**解决：在线估计环境参数，实时适配控制策略**

```
输入：
├── 本体感知（Proprioception）：关节位置、速度、力矩
├── 命令历史：历史动作序列
└── 观测历史

输出：
└── 自适应控制信号（考虑环境变化）
```

### 核心模块

| 模块 | 描述 | 运行频率 |
|-----|------|---------|
| **Base Policy** | 强化学习训练的 locomotion policy | 100 Hz |
| **Adaptation Module** | 基于历史预测环境参数（extrinsics） | 10 Hz |

### 训练方法：Domain Randomization + DAgger蒸馏

**第一阶段：Domain Randomization训练**

- 随机化仿真中的物理参数（质量×0.5~2.0、摩擦系数等）
- 策略见到各种环境变化，学会自适应
- 奖励函数：跟踪目标速度 + 最小化能量消耗 + 最小化冲击

```python
# 奖励函数设计（10项）
r = r_velocity_tracking + r_energy_minimize + r_impact_minimize + ...
```

**第二阶段：用DAgger蒸馏到在线适应模块**

```
训练数据收集：
1. 在仿真中用教师策略（知道真实extrinsics）生成数据
2. 学生策略用历史观测预测extrinsics
3. 监督学习：让学生模拟教师对extrinsics的估计
```

### 在线适应机制

**关键洞察：利用"命令-实际执行"的差异检测地形变化**

```
命令：前进速度 v
实际：观测到的位移 Δx

差异 = f(地形参数)
- 腿打滑 → 实际位移 < 预期
- 松软地面 → 需要更大推力
```

**Adaptation Module学习**：输入历史命令+实际响应 → 预测环境参数Z

### 真实世界实验结果

| 场景 | 结果 | 关键观察 |
|-----|------|---------|
| 油地面 | 成功通过 | 适应 slippery 条件，调整步态 |
| 背负5kg负载（机器人自重12kg） | 成功行走 | 检测到重量变化，增加扭矩 |
| 移动木板 | 成功通过 | 适应不稳定支撑面 |
| 泡沫床垫 | 成功通过 | 软质地形不影响 |
| 泥土/沙地 | 成功通过 | 足部陷入但能恢复 |

**对比实验：关闭Adaptation Module**

- 背负8kg负载：机器人前倾、无法抬腿（超出额定payload 3kg）
- 泡沫地面：陷入后无法恢复高度（不知道需要更大 clearance）

### 与其他基线方法对比

| 方法 | 描述 | 性能 |
|-----|------|-----|
| **Robust Policy** | 不给策略看环境参数，纯粹鲁棒化 | 保守，成功率低 |
| **System Identification** | 显式估计物理参数（摩擦、质量） | 比robust稍好，但估计本身很难 |
| **Fine-tune at Inference** | 真实世界微调 | 太慢，无法实时 |
| **RMA（Ours）** | 在线上下文适应 | 最佳 |

## 视觉+控制：端到端感知与动作耦合

### 传统方法的问题：显式建图（Explicit Mapping）

**传统方法流程：**
```
感知输入 → 重建3D地图 → 路径规划 → 控制命令
```

**问题：**
- 建图本身很难（遮挡、传感器噪声、累积漂移）
- 建图损失信息，且误差无法恢复
- 控制依赖地图质量，误差双重叠加

### 直接耦合方法：去除地图层

**核心思想：视觉输入直接进入控制策略，不经过中间表示**

```
RMA + Vision:
深度相机 → Adaptation Module → Base Policy → 电机控制

（无地图、无路径规划、直接端到端）
```

### 训练流程

**Phase 1：仿真训练（无感知）**
- 策略输入：完美地形高度图 + 本体感知
- 训练算法：PPO + Isaac Gym
- 奖励：跟踪目标速度 + 最小能量

**Phase 2：深度蒸馏（Depth Distillation）**

```python
# 用仿真中的完美高度图作为教师信号
# 学生网络从 egocentric depth image 学习预测相同信息

# DAgger风格蒸馏
for iteration in range(N):
    student_trajectory = student_policy(depth_image)
    teacher_trajectory = teacher_policy(perfect_height)
    loss = mse(student_trajectory, teacher_trajectory)
```

### 关键设计：RNN提供时间上下文

- 使用RNN（而非纯前馈网络）整合历史信息
- 历史信息帮助检测接触事件（contact detection）
- 论文未使用Transformer，但理论上可行

### 真实世界部署结果

| 场景 | 结果 |
|-----|------|
| 不均匀台阶（20cm高差） | 成功攀登，腿伸出侧面绕过 |
| 非常湿滑地面 | 持续尝试，最终成功 |
| 建筑碎片地形 | 尝试多次，逐渐找到路径 |
| 楼梯（上行/下行） | 成功（机器人身高仅30cm） |

**关键观察：步态是 emergent 的，非预定义**

- 没有预设步态模板
- 强化学习自己发现了"侧向抬腿"等技巧
- 步态平滑、有意图感

### 对比实验：Blind vs Map-based vs Direct Depth

| 地形类型 | Blind Policy | Map-based | Direct Depth (Ours) |
|---------|-------------|-----------|---------------------|
| 平地/坡 | 好 | 好 | 好 |
| 台阶 | 差 | 接近blind | 明显更好 |
| 不连续障碍 | 差 | 接近blind | 明显更好 |

**结论：对于需要精确放置脚掌的任务，纯深度方法显著优于基于地图的方法。**

## 灵巧操控与多形态扩展

### 灵巧手旋转物体（Dexterous Manipulation）

**任务：让机械手在手掌中旋转不同形状/材质的物体**

| 物体类型 | 重量范围 | 特点 |
|---------|---------|------|
| 冰球 | 轻 | 光滑表面 |
| 奇异果 | 轻~中 | 不规则形状 |
| 羽毛球（ shuttlecock） | 很轻 | 空气阻力大 |
| 方块/杯子 | 重 | 形状规则 |
| 硬币/ Adapter | 变化大 | 需精确控制 |

**关键发现：基于触觉历史的contact detection**

```
接触检测原理：
- 期望关节位置 vs 实际关节位置
- 接触时：实际位置 < 期望位置（被挡住）
- 无接触时：位置跟随命令

→ 网络从历史学会：当前状态是否在接触
→ 接触信息 → 推断物体形状/大小
```

### 无人机控制

**一个策略控制多种不同规格的四旋翼：**

| 参数 | 小型无人机 | 大型无人机 |
|-----|----------|----------|
| 重量 | 轻（基础重量4x lighter） | 重 |
| 臂长 | 短 | 长（3x longer） |
| 最大速度 | 高 | 低 |

**实验：**
- 4x重量差异 + 3x臂长差异 → 同一策略成功控制两者
- 策略在线估计 morphology 参数，自适应控制

## 人形机器人进展与挑战

### 当前进展

| 成果 | 描述 |
|-----|------|
| 双足行走 | 不稳定系统，比四足更难 |
| 舞蹈动作 | 全局实时控制 |
| 操控任务 | 接收语言指令、执行多样化任务 |

### 灵巧操控 vs 运动控制的差距

**运动控制为何已经work：**

| 因素 | 运动控制 | 灵巧操控 |
|-----|---------|---------|
| 仿真技术 | 刚体接触仿真成熟 | 柔性物体、切割等难以仿真 |
| 奖励定义 | 程序化（跟踪速度）= 完整任务定义 | 需要人工设计（切菜大小等）|
| 泛化能力 | 随机地形泛化 | 任务专一化，难以泛化 |

**核心结论：**
- 仿真成熟 + 奖励明确 → locomotion成功
- 仿真不成熟 + 奖励复杂 → manipulation仍是open problem

## 未来方向与开放问题

### 仿真技术的进步

**当前限制：**
- 柔性物体（面团、布料）仿真慢或不准确
- 复杂物理交互（切割、混合）无法仿真

**希望：随着算力提升，仿真能力会进步**

> "Betting on compute" — 算力即正义

### 通用奖励模型

**问题：**
- 每个新任务需要新奖励函数
- 人工设计奖励难以scale

**可能的解决方向：**

| 方向 | 乐观预测 | 悲观预测 |
|-----|---------|---------|
| 通用VLM作为奖励 | VLM理解世界，生成奖励 | RL会exploit VLM弱点 |
| 人类标注 | 人类可扩展（数十亿） | 标注成本/伤害 |
| 合成数据 | 可无限生成 | 难以覆盖真实分布 |

### 超越人类能力

**终极问题：机器人能否超越人类？**

| 领域 | 人类水平 | 机器人潜力 |
|-----|---------|-----------|
| 速度 | 受限于肌肉响应速度 | 电机响应更快 |
| 力量 | 受限于肌肉密度 | 电机扭矩更大 |
| 精确度 | 受限于神经延迟 | 可达微秒级控制 |
| 可靠性 | 疲劳、分心 | 持续稳定 |

**AlphaGo的启示：** 稀疏奖励 + 大量搜索 → 超越人类直觉的新招法

**机器人领域的对应路径：**
- 稀疏奖励（任务完成与否）
- 强化学习自动化探索
- 发现超越预设策略的新行为

## 本讲小结

### 核心要点

| 技术 | 核心思想 | 关键创新 |
|-----|---------|---------|
| RMA | 在线估计环境参数 | 利用命令-执行差异检测地形 |
| Direct Depth | 去掉地图层，端到端控制 | 深度蒸馏避免渲染开销 |
| Contact Detection | 从本体感知历史推断接触 | 不需要视觉 |

### 为什么机器人灵巧操控仍是open problem

1. **仿真不成熟**：无法准确模拟变形、切割等
2. **奖励复杂**：任务相关，每任务需单独设计
3. **泛化困难**：学到的是单一技能，非通用能力

### 启发

- **上下文学习 > 显式估计**：不显式估计物理参数，而是用历史上下文"隐式"适应
- **直接耦合 >  Pipeline**：去除中间表示，直接端到端学习
- **任务设计影响深远**：稀疏、明确的奖励是成功的关键
