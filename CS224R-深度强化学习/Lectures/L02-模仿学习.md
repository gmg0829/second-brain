# Stanford CS224R | 模仿学习 | 第2讲

## 模仿学习问题设置

**核心思想**：不从头摸索，而是模仿专家的行为

- **给定**：专家演示轨迹数据集 D = {τ₁, τ₂, ..., τₙ}，每条轨迹包含 (s, a) 对
- **目标**：学习策略 π_θ，使其行为与专家相似或更优
- **优点**：无需设计奖励函数，直接从演示中学习
- **缺点**：需要大量高质量专家数据，且分布偏移会导致误差累积

### 典型应用场景

| 应用 | 专家数据形式 | 挑战 |
|------|-------------|------|
| **自动驾驶** | 传感器数据 + 方向盘/油门/刹车命令 | 多模态（不同并线策略） |
| **机器人操作** | 折叠衣物、组装零件的关节角度序列 | 高维连续动作空间 |
| **手术机器人** | 医生操作的手术视频+关节指令 | 安全要求高，容错率低 |
| **对话系统** | 人机对话示范 | 开放式序列生成 |

## L2回归（行为克隆 / Behavioral Cloning）

### 方法

```python
# 最小化预测动作与专家动作的L2距离
min_θ Σ_{(s,a)∈D} ||π_θ(s) - a||²
```

- 本质上是一个标准的监督学习问题
- 策略 π_θ 是一个分类器或回归器
- 训练数据：从专家轨迹中提取的 (状态, 动作) 对

### 问题：多模态数据

**核心矛盾**：不同演示者可能采取不同动作，但L2回归会预测"平均动作"

```
示例场景：十字路口左转
- 动作A distribution：均值=0（直行），方差=0.5
- 动作B distribution：均值=-2（左转），方差=0.5
- 混合 distribution 均值可能在两条 lane 之间 → 危险！

问题：均值动作可能是低概率甚至从未被演示过的动作
```

- **均值回归陷阱**：预测均值在多峰分布下可能完全无效
- **误差累积（Compounding Errors）**：小错误会在长轨迹中放大
  - 策略偏离 → 进入未见过的状态 → 更大概率犯错 → 更大偏离

## 解决方案：表达性动作分布

**核心思想**：策略输出分布参数，而非单一动作值

| 动作类型 | 分布选择 | 表达力 | 适用场景 |
|----------|----------|--------|----------|
| 离散动作 | Categorical分类 | ★★★★★ | 离散选择（菜单、方向） |
| 连续动作 | 高斯混合 GMM | ★★★★☆ | 多峰行为（并线vs直行） |
| 连续动作 | 单高斯 | ★★☆☆☆ | 单峰行为 |
| 高维连续 | 自回归 + Discretization | ★★★★★ | 机器人关节序列 |

### 方法1：混合高斯（GMM）

```python
# 神经网络输出K个高斯分量的参数
π_θ(s) → {μ_k, σ_k, w_k}_{k=1}^K
p(a|s) = Σ_k w_k · N(a | μ_k, σ_k)

# K=2 时可以建模双峰行为（左转/右转）
# K=3+ 可以建模更复杂的多模态
```

- **优势**：连续可微，可用梯度优化
- **劣势**：难以建模高度复杂的多模态分布

### 方法2：自回归模型（类似语言模型）

```python
# 动作向量的每个维度顺序建模
p(a|s) = p(a₁|s) · p(a₂|s, a₁) · p(a₃|s, a₁, a₂) · ...

# 类似生成长句子：每个词依赖于前面的词
```

- **Discretization**：将连续动作分成离散的bins，输出每个bin的概率
  - 类似语言模型预测下一个词
  - 可以处理高维动作空间
- **维度顺序**：可手动指定（如机器人关节按运动链顺序）
- **网络架构**：可用RNN/LSTM/Transformer处理长动作序列
  - Transformer自注意力可以捕获动作维度间的依赖

### 方法3：扩散模型（Diffusion Models）

- **迭代去噪过程**：从纯噪声开始，迭代去噪生成动作
- **适合场景**：高维连续动作空间（如机器人手臂的关节角度序列）
- **优势**：可以建模极其复杂的动作分布
- **代表工作**：Diffuser、Decision Diffuser

### 方法对比

| 方法 | 表达力 | 计算成本 | 训练稳定性 | 多模态建模 |
|------|--------|----------|------------|------------|
| 单高斯 | ★★☆☆☆ | 低 | 高 | 差 |
| GMM | ★★★★☆ | 中 | 中 | 较好 |
| 自回归 | ★★★★★ | 高 | 中 | 好 |
| 扩散模型 | ★★★★★ | 高 | 中 | 最好 |

## 训练目标：最大似然

```python
# 最大似然估计
min_θ -E_{(s,a)∈D}[log π_θ(a|s)]

# 效果：使策略对专家动作赋予高概率
```

- **GMM**：写出概率密度函数，求导用梯度下降
- **离散自回归**：交叉熵损失，等同于分类问题
- **连续自回归**：类似语言模型的next-token预测

## 何时需要表达性分布？

| 数据来源 | 推荐策略 | 原因 |
|----------|----------|------|
| 单一日渐一致的演示者 | 确定性策略或单高斯 | 数据本身是单峰的 |
| 多演示者、多样化策略 | **必须用表达性分布** | 数据本身是多峰的 |
| 复杂长序列动作 | 自回归或扩散模型 | 动作维度间有依赖 |

- **实验结论**：Diffusion模型在多样化数据上显著优于L2回归
- **实践建议**：先用简单方法（如GMM），如果效果不好再升级到更复杂模型

## 在线干预：DAgger

### 问题根源

**误差累积**：只模仿会随时间放大错误

```
状态s₁ → 策略预测动作a₁（有小误差）
→ 到达s₂（与专家不同）
→ 策略预测a₂（误差更大）
→ ...
→ 最终策略崩溃
```

### DAgger算法流程

**迭代收集专家干预数据**

```
1. 用当前策略 π_θ 收集 trajectory
2. 遇到困难状态 → 让专家演示正确动作
3. 将 (状态, 专家动作) 加入训练数据
4. repeat（通常3-5次迭代）
```

| 迭代 | 策略质量 | 数据分布 | 效果 |
|------|----------|----------|------|
| 1 | 差 | 主要来自专家初始 | 快速学习基础行为 |
| 2-3 | 中 | 覆盖更多状态 | 修复累积误差 |
| 4-5 | 好 | 接近目标分布 | 精调至收敛 |

- **关键洞察**：不仅要学动作，要学"在什么状态下做什么动作"
- **与在线RL的区别**：DAgger不需要奖励函数，只依赖专家干预信号

## Offline vs 在线模仿学习

| 类型 | 数据收集 | 优点 | 缺点 |
|------|----------|------|------|
| **离线** | 仅使用已有数据集 | 安全、可复用、样本效率高 | 分布偏移导致误差累积 |
| **在线** | 边收集边学习 | 策略可以主动探索 | 需要环境交互、成本高 |

- **离线模仿学习**：Behavior Cloning、Learning from Observations
- **在线模仿学习**：DAgger、Chain of Thought Imitation

## 模仿学习的局限性

- **分布偏移**：策略和专家的数据分布不同，误差会累积
- **因果混淆（Causal Confusion）**：可能学到的是相关性而非因果性
  - 示例：专家转弯时总是同时转方向盘+倾斜身体 → 策略可能误学倾斜导致转弯
- **需要大量数据**：需要覆盖各种状态的数据，否则无法泛化
- **无法超越专家**：最多达到专家平均水平（除非用在线方法探索）
