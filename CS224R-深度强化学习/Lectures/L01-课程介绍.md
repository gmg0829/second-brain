## 课程目标与内容

- 掌握深度强化学习的核心理念与算法，重点是**可扩展到深度神经网络**的解决方案
- 课程涵盖四大主题：
  - 模仿学习（Imitation Learning）：从专家演示中学习策略

  - 基于模型的强化学习（Model-Based RL）：学习环境动力学模型
  - 离线/在线强化学习（Offline/Online RL）：数据分布偏移问题

  - **LLM强化学习**（RLHF/DPO等）：几乎所有现代语言模型都使用RL进行后训练
  - **机器人强化学习**：Sim-to-Real迁移，从仿真环境训练到真实世界部署

## 为什么学习深度强化学习？

**核心场景：AI决策有后果，且需要优化这些后果**

| 传统监督学习 | 深度强化学习 |
|-------------|--------------|
| 标签（label）直接可得 | 仅通过 indirect feedback 间接学习 |
| 数据i.i.d.独立同分布 | 数据分布依赖当前策略 |
| 输入→输出直接映射 | 动作影响未来观测，形成序列决策 |

- **例子：Spotify推荐歌曲**——当前推荐影响下一次推荐的结果，形成依赖关系
- **无直接监督**：如 coding assistant 的反馈（好/差）不是模型输出的一部分，需要从环境获取
- **序列决策本质**：每个动作都会影响后续状态和信息，决策是序贯的
- **基本能力**：从经验中学习是智能的核心——AlphaGo、机器人、自动驾驶都依赖RL

## 强化学习问题建模

### 状态 vs 观测

- **状态（s）**：世界的完整描述，包含所有决策所需信息
- **观测（o）**：智能体观察到的部分信息，可能只包含部分世界状态
  - 示例：聊天机器人只看到最近一条消息，看不到对话历史全貌
  - 当 o = s 时，称为"完全可观测"（Full Observability）

### 核心组件

- **状态转移 P(s'|s, a)**：环境的动态模型，描述执行动作后世界如何变化
- **动作 a**：智能体可以采取的行为
- **轨迹 τ = (s₁, a₁, s₂, a₂, ...)**：从开始到结束的完整行为序列
- **奖励函数 r(s, a)**：评估状态-动作对好坏的关键信号
- **策略 π(a|s)**：从状态到动作的映射，通常是神经网络（深度强化学习中的"深度"）

### MDP框架

```
P(s'|s, a) — dynamic模型（世界如何变化）
π_θ(a|s)   — 策略（神经网络参数θ）
r(s, a)    — 奖励（衡量好坏）
```

**马尔可夫性**：下一个状态 s' 仅依赖于当前状态 s 和动作 a，与更早的历史无关
- 这使得问题具有"无记忆性"，简化了决策过程
- 真实世界可能不满足马尔可夫性，但常作为近似假设

## 强化学习目标

### 目标函数

**maximize期望累计奖励**——找到最优策略 θ* 使期望回报最大

```python
J(θ) = E_{τ~p_θ(τ)} [ Σ_t r(s_t, a_t) ]
```

其中轨迹概率：
```python
p_θ(τ) = p(s₁) Π_t π_θ(a_t|s_t) P(s_{t+1}|s_t, a_t)
```

### 折扣因子（Discount Factor）

- **折扣 γ ∈ [0, 1)**：对未来奖励进行指数衰减打折
  - γ = 1：平等对待所有奖励（数学上方便，但实际训练困难）
  - γ = 0：只关注即时奖励（短视策略）
  - γ = 0.99：常见设置，重视未来但不过度
- **直观理解**：折扣相当于每步有 (1-γ) 概率终止当前轨迹
- **收敛性保证**：折扣因子使无限时域问题变成有限期望，策略梯度算法更稳定

## 策略类型

| 类型 | 特点 | 适用场景 | 示例 |
|------|------|----------|------|
| **随机策略** | 输出动作分布 π(a\|s) | 探索环境、学习多模态行为 | 机器人操作、对话系统 |
| **确定性策略** | 输出单一动作 a = μ(s) | 确定性强时可接受 | Atari游戏、简单控制 |

- **随机策略必要性**：
  1. **探索（Exploration）**：智能体需要尝试不同动作发现好策略
  2. **建模演示者多样性**：专家数据往往包含多种合理动作
  3. **多模态输出**：同一状态可能有多个好动作（如并线vs直行）

## 价值函数

### 三种核心函数

| 函数 | 定义 | 公式 |
|------|------|------|
| **V^π(s)** | 从状态s开始，按策略π行动的期望累计奖励 | V^π(s) = E_π[Σ_t γ^t r_t \| s₀=s] |
| **Q^π(s, a)** | 从状态s开始，先执行动作a，再按π行动的期望累计奖励 | Q^π(s, a) = E_π[Σ_t γ^t r_t \| s₀=s, a₀=a] |
| **A^π(s, a)** | 动作a相比策略π平均水平的优势 | A^π(s, a) = Q^π(s, a) - V^π(s) |

### 关键关系

```python
V^π(s) = E_{a~π(·|s)} [ Q^π(s, a) ]           # 状态价值 = 动作价值的期望
A^π(s, a) = Q^π(s, a) - V^π(s)                 # 优势 = 动作价值 - 平均价值
```

- **V^π(s)**：评估当前状态好坏，不考虑具体动作
- **Q^π(s, a)**：评估在状态s下采取动作a的好坏
- **A^π(s, a)**：正值表示动作a优于平均，负值表示劣于平均

### 贝尔曼方程

```python
V^π(s) = E_{a~π(s)} [ r(s, a) + γ E_{s'~P(s'|s,a)} [ V^π(s') ] ]
Q^π(s, a) = r(s, a) + γ E_{s'~P(s'|s,a)} [ V^π(s') ]
```

- 价值函数可以通过自举（bootstrapping）从其他价值估计中学习
- 最优策略 π* 对应 V*(s) = max_π V^π(s)
