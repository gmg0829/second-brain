## 探索-利用困境 (Exploration-Exploitation Trade-off)

### 核心定义

| 概念 | 定义 | 目标 |
|------|------|------|
| **利用 (Exploitation)** | 基于当前知识选择最优动作 | 最大化即时奖励 |
| **探索 (Exploration)** | 选择信息不确定的动作 | 发现更好的长期策略 |

**数学表达**：
$$\underbrace{\sum_{t=0}^{T} r(s_t, a_t)}_{\text{总奖励}} = \underbrace{\sum_{t=0}^{T} \mathbb{E}[r(s_t, a_t^{\text{greedy})]}_{\text{利用}} + \underbrace{\text{Remainder}}_{\text{探索收益}}$$

### 为什么探索困难？

| 问题 | 描述 | 示例 |
|------|------|------|
| **稀疏奖励** | 奖励信号极少，难以指导学习 | Montezuma's Revenge 游戏 |
| **长期信用分配** | 早期动作的后果可能很久后才显现 | 需要多步计划的任务 |
| **维度灾难** | 高维状态/动作空间难以覆盖 | 机器人控制、图像输入 |
| **非平稳性** | 环境可能随时间变化 | 推荐系统用户偏好漂移 |

## 多臂老虎机 (Multi-Armed Bandit)

### 问题定义

**老虎机问题**：$K$ 个拉杆，每个拉杆 $i$ 的奖励分布为 $r_i \sim P(r \mid i)$。

**累计 regret 定义**：
$$R(T) = T \cdot \mu^* - \sum_{t=1}^{T} \mu_{a_t}$$

其中：
- $\mu^* = \max_i \mu_i$（最优拉杆的期望奖励）
- $\mu_i = \mathbb{E}[r_i]$（第 $i$ 个拉杆的期望奖励）
- $a_t$：时刻 $t$ 选择的拉杆

**Regret 的意义**：
- $R(T) = O(T)$：线性增长，算法没有学习
- $R(T) = O(\sqrt{T})$：次线性，可接受
- $R(T) = O(\log T)$：接近最优

### 经典算法对比

| 算法 | 探索机制 | Regret 上界 | 特点 |
|------|----------|-------------|------|
| **Greedy** | 无（只看历史最优） | $O(T)$ | 收敛到局部最优 |
| **ε-Greedy** | 以概率 ε 随机 | $O(T^{2/3})$ | 简单但次优 |
| **UCB1** | 上置信界：$\hat{\mu}_i + \sqrt{\frac{2\ln t}{N_i}}$ | $O(\sqrt{T})$ | 分析简洁 |
| **Thompson Sampling** | 贝叶斯后验采样 | $O(\sqrt{T})$ | 实现简单，效果好 |

### Upper Confidence Bound (UCB) 详解

**选择动作**：
$$a_t = \arg\max_i \left( \hat{\mu}_i(t-1) + \sqrt{\frac{2\ln t}{N_i(t-1)}} \right)$$

其中：
- $\hat{\mu}_i(t-1)$：截至 $t-1$ 的样本均值
- $N_i(t-1)$：拉杆 $i$ 被选择的次数
- 第二项：置信上界（鼓励探索少被选择的拉杆）

**直觉**：如果一个拉杆被选了很多次，我们对它的估计就准确；如果被选得少，置信界就宽。

### Thompson Sampling 详解

**贝叶斯方法**：

```python
def thompson_sampling(rewards_history, priors):
    # 1. 对每个拉杆维护 Beta 分布后验
    for i in range(K):
        alpha_i, beta_i = posterior_beta(priors[i], rewards_history[i])
        # 2. 从后验采样
        sampled_mean[i] = beta_sample(alpha_i, beta_i)
    
    # 3. 选择采样值最高的拉杆
    return argmax(sampled_mean)
```

**数学**：若奖励服从 Bernoulli，$N_i$ 次试验中 $S_i$ 次成功，则后验为：
$$p(\theta_i \mid \mathcal{D}_i) = \text{Beta}(\alpha_0 + S_i, \beta_0 + N_i - S_i)$$

**优点**：
- 自然平衡 exploration-exploitation
- 实现简单，无需手动调 ε
- 实践中通常优于 UCB

## MDP 中的探索

### tabular MDP

**状态可枚举** → 可精确追踪访问计数

$$N(s, a) += 1 \quad \forall (s, a) \text{ visited}$$

**Count-based 探索**：奖励 bonus 与 $1/\sqrt{N(s,a)}$ 成正比

$$r^+(s,a) = r(s,a) + \beta \cdot \frac{1}{\sqrt{N(s,a)}}$$

### 连续状态空间

**问题**：无法精确计数，需要近似方法。

| 方法 | 思想 | 适用场景 |
|------|------|----------|
| **伪计数 (Pseudo-count)** | 用密度模型估计 visit count | 低维连续 |
| **密度模型** | $p(s)$ 概率高的区域 = 常访问 | 视频预测 |
| **轨迹计数** | 状态-动作序列的整体新颖度 | 稀疏奖励 |

## 内在激励 (Intrinsic Motivation)

### 核心思想

$$r_t^{\text{total}} = r_t^{\text{extrinsic}} + \beta \cdot r_t^{\text{intrinsic}}$$

其中内在激励衡量"信息增益"或"新颖度"。

### Intrinsic Curiosity Module (ICM)

**Dynamics 预测误差**：
$$r_t^{\text{ICM}} = \|\hat{f}(s_t, a_t; \theta_f) - s_{t+1}\|^2$$

**为什么有效**：
- 新颖状态 → 预测误差大 → 激励探索
- 熟悉状态 → 预测误差小 → 不给激励

```python
# ICM 伪代码
def compute_intrinsic_reward(s_t, a_t, s_next, f_encoder, f_predictor):
    phi_t = f_encoder(s_t)          # 状态特征
    phi_next = f_encoder(s_next)
    phi_pred = f_predictor(phi_t, a_t)  # 预测下一步特征
    return ||phi_pred - phi_next||²   # 预测误差作为奖励
```

### Random Network Distillation (RND)

**核心思想**：训练一个网络预测固定随机初始化网络的输出。

```python
class RND:
    def __init__(self):
        self.fixed_net = RandomNetwork()  # 随机初始化，固定
        self.predictor = TrainableNetwork()
    
    def intrinsic_reward(self, s):
        return ||self.predictor(s) - self.fixed_net(s)||²
```

**直觉**：
- 对于新颖状态，随机网络和训练网络输出差异大
- 对于熟悉状态，训练网络已学会预测，差异小

### 对比

| 方法 | 激励来源 | 优点 | 缺点 |
|------|---------|------|------|
| **ICM** | 预测误差 | 端到端学习 | 需训练 inverse model |
| **RND** | 预测固定随机网络 | 无需收集 bonus 数据 | 随机网络可能不够信息量 |
| **Count-based** | 访问计数 | 理论基础好 | 高维空间难以精确计数 |

## 元强化学习中的探索

### 问题 Formulation

**元 RL 测试时探索**：
- 新任务只有 $K$ 个 episode 的交互预算
- 必须高效探索
- Exploration 策略必须从元训练泛化到新任务

### 学到的 Exploration

**端到端方法**（如 Black-Box Meta-RL）：
- 序列模型自动学习利用历史判断任务
- 历史信息包含探索结果
- 无需手动设计 exploration 策略

### 探索目标的解耦

**分离 Exploration 和 Exploitation**：

```python
# Exploration 策略
π_explore(a | s, H)
    ↓ 生成经验
Task Inference Network: q(z | H)
    ↓ 推断任务
# Exploitation 策略
π_exploit(a | s, z)
```

**优点**：
- 目标解耦，优化更稳定
- Exploration 专门优化"学习任务"而非"执行任务"

## 变分信息瓶颈 (Variational Information Bottleneck)

### 目标

学习压缩的、可泛化的任务表示。

### 方法

```python
class VIB:
    def __init__(self):
        self.encoder = Encoder()      # μ, σ
        self.policy = Policy()
    
    def forward(self, s, z, epsilon):
        z_perturbed = z + epsilon  # 添加噪声
        return self.policy(s, z_perturbed)
    
    def loss(self, s, a, z, reward):
        # RL 损失
        rl_loss = -reward
        
        # KL 正则化
        kl_loss = KL(q(z|s) || N(0,1))
        
        return rl_loss + beta * kl_loss
```

**效果**：
- 噪声迫使表示压缩无关信息
- 只保留解决任务所需的信息
- 可泛化到新任务

## 实践建议

### 算法选择

| 环境特点 | 推荐算法 |
|---------|----------|
| **Bandit (单状态)** | Thompson Sampling, UCB |
| **tabular MDP** | Count-based + UCB |
| **低维连续** | SAC + curiosity bonus |
| **高维图像** | ICM, RND, Dreamer |
| **元 RL** | Black-box + memory |

### 探索激励的权衡

| 因素 | 激励太强 | 激励太弱 |
|------|---------|---------|
| **表现** | 探索多代，奖励少 | 陷入局部最优 |
| **收敛** | 慢 | 可能永远不学 |
| **调试** | 看起来在随机行动 | 看起来完全利用 |

### 实践技巧

1. ** annealing**：随时间减少探索激励
2. **混合激励**：多来源组合（ICM + RND）
3. **分层探索**：高层探索目标，低层探索实现
4. **课程学习**：从简单到复杂逐步增加探索难度

## 总结

1. **探索核心**：平衡已知最优动作和未知动作的信息价值
2. **Regret 框架**：衡量算法相对最优策略的累积损失
3. **经典方法**：UCB（分析简单）、Thompson Sampling（实践好）
4. **内在激励**：ICM、RND 等自动发现新颖状态
5. **大规模问题**：依赖表示学习、预训练模型
6. **元 RL**：探索策略可学习并泛化到新任务
