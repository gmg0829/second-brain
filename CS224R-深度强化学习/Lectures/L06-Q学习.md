## Q函数与Bellman方程

- **Q函数 Q(s, a)**：状态-动作对的期望累计折扣奖励，衡量在状态s下采取动作a的长期价值
  - 数学定义：Q(s, a) = E[r_t + γr_{t+1} + γ²r_{t+2} + ... | s_t=s, a_t=a]
  - 其中γ ∈ [0,1]为折扣因子，权衡即时奖励与未来奖励的重要性
  - 折扣因子接近1时，智能体更注重长期回报；接近0时更注重即时奖励
  - Q函数是强化学习的核心概念，几乎所有值学习方法都围绕Q函数展开

- **Bellman方程**：将长期价值递归分解为即时奖励加上下一步价值的折扣
  - 推导：Belleman方程的核心思想是"当前价值 = 即时奖励 + 未来价值的折扣"
  - 最优Q函数满足：Q*(s, a) = E[r + γ max_{a'} Q*(s', a')]
  - 这是一个自洽方程，允许通过迭代方法求解——已知Q(s', a')可求Q(s, a)

- **贪婪策略 π_greedy(s)**：选择Q值最大的动作，直接利用当前知识
  - a* = argmax_a Q(s, a)，确定性策略，无需探索
  - 在已知Q函数的情况下是最优选择，但无法发现新价值
  - 与ε-greedy形成对比：贪婪=开发(exploitation)，ε-greedy=探索(exploration)

## 值迭代与策略迭代

- **值迭代(Value Iteration)**：直接迭代求解最优Q值，无需显式策略
  - 初始化Q(s, a) = 0，对所有状态动作对
  - 迭代更新：对每个(s, a)，用Bellman方程更新Q值
  - 收敛到唯一最优Q*函数，适用于小状态空间（如FrozenLake的16个状态）
  - 优点：实现简单，保证收敛；缺点：大状态空间不可行

- **策略迭代(Policy Iteration)**：交替进行策略评估与策略改进两个步骤
  - 策略评估：给定当前策略π，计算V^π(s)或Q^π(s, a)
  - 策略改进：基于评估结果，用贪婪策略提取新策略：π'(s) = argmax_a Q^π(s, a)
  - 重复直到策略收敛，理论上比值迭代收敛更快（通常只需少量迭代）
  - 每一步改进都能保证严格提升或保持性能

- **两种方法的对比**：值迭代隐式优化策略，策略迭代显式维护策略
  - 小规模问题（状态数<10^6）：策略迭代通常更快收敛
  - 大规模问题：两者都不可行，需要函数近似（深度学习）
  - 现代强化学习：几乎都使用策略梯度方法而非直接值迭代

## 深度Q网络(DQN)

- **核心思想**：用深度神经网络Q(s, a; θ)近似最优Q函数Q*(s, a)
  - 输入：状态s（可以是原始像素或提取的特征）
  - 输出：每个动作的Q值，或状态-动作对的标量Q值
  - 网络参数θ通过梯度下降优化，使Q(s, a; θ)逼近真实价值

- **经验回放(Experience Replay)**：存储转移元组(s, a, r, s')到replay buffer
  - 打破时序相关性：连续经历的样本相关性高，直接训练不稳定
  - 随机小批量采样：每次从buffer中随机抽取一批样本进行更新
  - 常用设置：buffer大小10^5~10^6，更新时随机采样32/64/128个样本
  - 实现：python
    ```python
    replay_buffer = ReplayBuffer(capacity=1000000)
    # 存储: replay_buffer.add(s, a, r, s', done)
    # 采样: batch = replay_buffer.sample(batch_size=64)
    ```
  - Off-policy学习：buffer中的数据来自旧策略，可被新策略反复利用

- **目标网络(Target Network)**：定期复制online network参数作为target，稳定TD学习
  - 问题：TD目标 r + γ max_{a'} Q(s', a'; θ) 依赖于正在更新的参数θ，导致训练不稳定
  - 解决：维护一个延迟更新的target网络，参数θ⁻
  - 目标值计算：y_i = r_i + γ max_{a'} Q(s'_i, a'; θ⁻)
  - 更新频率：每10000步（Atari）或每几秒复制一次online网络到target
  - 损失函数：L(θ) = E[(Q(s_i, a_i; θ) - y_i)²]，均方误差回归

- **DQN伪代码核心**：
  ```python
  # 初始化Q网络和target网络（参数相同）
  Q, Q_target = create_network(), create_network()
  Q_target.load_state_dict(Q.state_dict())

  for step in range(num_steps):
      # ε-greedy探索选择动作
      a = epsilon_greedy(Q, state, epsilon)

      # 与环境交互，存储经验
      next_state, reward, done = env.step(a)
      replay_buffer.add(state, a, reward, next_state, done)

      # 随机采样批量更新
      batch = replay_buffer.sample(batch_size=32)
      # 用target网络计算目标值（冻结参数）
      y = r + gamma * max_a Q_target(s', a) * (1 - done)
      # 更新Q网络参数（梯度反向传播）
      loss = mse(Q(s, a), y)
      optimizer.zero_grad(); loss.backward(); optimizer.step()

      # 定期同步target网络
      if step % target_update_freq == 0:
          Q_target.load_state_dict(Q.state_dict())
  ```

## 过度估计问题与Double DQN

- **过度估计(Overestimation) Problem**：max操作导致Q值被系统性高估
  - 原因：max_{a'} Q(s', a') 选取最大Q值，但最大Q值往往被高估（统计偏误）
  - 即使单个动作的Q值只有微小高估，选择最大值的操作会放大这一偏差
  - 高估会传播：Belleman方程迭代中，高估的Q值会导致更大的TD目标
  - 在实际任务中可能导致学习次优策略，特别是初始阶段

- **Double DQN (DDQN)**：用online network选择动作，用target network评估价值
  - 动机：将"选择动作"和"评估动作"解耦，避免选择被高估的动作
  - 动作选择：用当前online网络Q(s', a; θ)选择最优动作a*
  - 价值评估：用target网络Q(s', a*; θ⁻)评估该动作的价值
  - 目标值修正：y_i = r_i + γ Q(s'_i, argmax_{a'} Q(s'_i, a'; θ), θ⁻)
  - 效果：DeepMind实验显示DDQN在Atari上显著减少过度估计，策略质量更高

- **过度估计的实验证据**：
  - Atari 2600游戏：用Naive DQN学习的策略经常选择次优动作
  - DDQN vs DQN：DDQN在23/57个游戏中取得更好成绩，无一更差
  - 过度估计在稀疏奖励环境中尤其严重

## 探索策略

- **ε-Greedy探索**：以概率ε随机选择动作，1-ε概率贪婪选择
  - 平衡探索与利用：初期ε大（随机多），逐渐衰减到小值
  - 衰减策略：ε = max(ε_min, ε_start * ε_decay^{step})
  - 典型参数：ε_start=1.0, ε_min=0.01, ε_decay≈0.999（百万步级别）
  - 优点：实现简单，有效；缺点：均匀随机，无法利用奖励信号引导探索

- **Boltzmann探索**：基于Q值的softmax概率分布选择动作
  - 概率：P(a) ∝ exp(Q(s, a) / τ)，τ为温度参数
  - 高温τ→∞：趋近均匀随机；低温τ→0：趋近贪婪策略
  - 可自适应调整：奖励信号多的动作概率自然提高
  - 优点：利用价值差异引导探索；缺点：需要调参τ

## 高级技巧与算法变体

- **N-Step Returns**：混合多步TD与单步TD，平衡偏差与方差
  - 1-step TD：y_t = r_t + γQ(s_{t+1})
  - n-step TD：y_t = r_t + γr_{t+1} + ... + γ^{n-1}r_{t+n-1} + γ^n Q(s_{t+n})
  - n越大：偏差小、方差大；n=1：偏差大方差小
  - 常用n=4~5（如Ape-X DQN使用）

- **Dueling DQN**：分离状态价值V(s)和动作优势A(s, a)
  - 网络结构：共享卷积特征提取器 → 分叉为V(s)和A(s, a)
  - Q(s, a) = V(s) + A(s, a) - mean_a[A(s, a)]（优势函数去中心化）
  - 好处：能分别学习"状态有多好"和"动作相对平均有多好"
  - 优势：特别适合那些许多动作价值相近的状态

- **Prioritized Experience Replay (PER)**：优先回放高TD误差的样本
  - 采样概率：P(i) ∝ |δ_i|^α（TD误差δ_i的绝对值）
  - 重要性采样修正：用IS权重平衡非均匀采样
  - α=0时退化为均匀采样，α=1时完全优先高TD误差样本
  - 效果：在Atari上获得显著提升

## 彩虹算法(Rainbow)

- **彩虹算法**：整合7种DQN变体的最佳技巧于一身
  - 组件：Double DQN + Dueling DQN + PER + Noisy Nets + Distributional RL + N-Step + APE-X
  - Noisy Nets：用可学习噪声替代ε-greedy，实现自适应探索
  - Distributional RL：预测奖励的完整分布而非仅期望值
  - 每种技巧互补：PER解决样本效率，DDQN减少过度估计，Dueling分离状态/动作价值

- **性能对比（Atari 57 games）**：
  - Rainbow：人类水平性能的477%，远超任一单一组件
  - 单独最好：Distributional RL (442%)，PER (428%)，Dueling (416%)
  - Rainbow > 线性组合，说明组件间有正向协同效应

## 实际应用案例

- **Atari 2600游戏**：深度强化学习的里程碑
  - 输入：原始屏幕像素（210×160×3），无需手工特征
  - 卷积神经网络处理视觉输入，输出560种可能动作的Q值
  - 训练：固定折扣γ=0.99，replay buffer 100万帧，ε衰减到0.1
  - 结果：DQN在49游戏中41个达到人类水平以上（83.7%）
  - 代表游戏：Space Invaders, Breakout, Pong等

- **机器人抓取(Google Brain)**：DQN在真实机器人任务中的应用
  - 任务：机械臂从未知杂乱场景中抓取目标物体
  - 状态：RGB-D相机图像 + 机械臂关节角度
  - 动作：末端执行器的3D位置和旋转
  - 奖励：+1成功抓取并举起物体，否则0
  - 结果：96%成功率，泛化到训练未见过的物体和场景
  - 意义：首次展示端到端学习在真实机器人上的可行性

## 算法对比总结

| 算法 | 策略类型 | 样本效率 | 稳定性 | 适用场景 |
|------|----------|----------|--------|----------|
| **DQN** | Off-policy | 高（经验回放） | 中等（需要target网络） | 离散动作，视觉输入 |
| **Double DQN** | Off-policy | 同DQN | 更好（减少过度估计） | 需要更精确Q值估计 |
| **Dueling DQN** | Off-policy | 同DQN | 中等 | 状态价值变化大时 |
| **PPO** | On-policy | 低（需大量采样） | 高（信任域约束） | 连续/离散，动作空间大 |
| **SAC** | Off-policy | 高 | 高（熵正则化） | 连续控制，机器人 |
