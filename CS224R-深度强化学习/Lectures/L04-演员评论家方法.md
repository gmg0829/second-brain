## 策略梯度的问题

### 核心问题：高方差

**用单条轨迹的样本回报估计梯度，方差高**

```
传统策略梯度：
∇_θ J ≈ Σ_t ∇_θ log π(a_t|s_t) · G_t  （G_t = Σ_{t'=t}^T r_{t'}）

问题：G_t 是单个样本的累计奖励，随机性很大
```

### 具体示例

**机器人走迷宫问题**：
- 机器人先迈步向前 → 然后摔倒
- 整条轨迹的累计奖励为负（-1）
- 传统PG会把"迈步向前"视为负面动作（因为总奖励为负）
- 但实际上"迈步向前"可能是正确决策，只是后来摔倒导致负奖励

**问题本质**：
- 单条轨迹的奖励取决于整条轨迹的所有动作
- 好动作可能被坏动作"拖累"
- 早期动作的"贡献"被后期奖励"污染"

### 解决思路

**估计每个动作的"真实价值"（基于统计期望），而非只看单条样本结果**

## 价值函数回顾

### 三种核心函数

| 函数 | 定义 | 公式 |
|------|------|------|
| **V^π(s)** | 状态价值：从状态s开始，按策略π行动的期望累计奖励 | V^π(s) = E_π[Σ_t γ^t r_t \| s₀=s] |
| **Q^π(s, a)** | 动作价值：从状态s开始，先执行动作a，再按π行动的期望累计奖励 | Q^π(s, a) = E_π[Σ_t γ^t r_t \| s₀=s, a₀=a] |
| **A^π(s, a)** | 优势函数：动作a相比策略π平均水平的优势 | A^π(s, a) = Q^π(s, a) - V^π(s) |

### 关键关系

```python
V^π(s) = E_{a~π(·|s)} [ Q^π(s, a) ]     # 状态价值 = 动作价值的期望
A^π(s, a) = Q^π(s, a) - V^π(s)           # 优势 = 动作价值 - 平均价值
```

### 优势函数的直觉

| A^π(s, a) | 含义 | 策略调整 |
|-----------|------|----------|
| A > 0 | 动作a优于策略π的平均水平 | 增加概率 |
| A = 0 | 动作a等于平均水平 | 不变 |
| A < 0 | 动作a劣于平均水平 | 减少概率 |

## 演员评论家梯度（Actor-Critic Gradient）

### 核心思想

**用价值函数估计替代简单样本回报**，用优势函数引导更新方向

```python
# 演员评论家梯度
∇_θ J(θ) = E_{τ~π_θ} [ Σ_t ∇_θ log π_θ(a_t|s_t) · A^π(s_t, a_t) ]
```

**直觉理解**：
- 用 A^π(s_t, a_t)（优势）替代 G_t（样本回报）
- 优势函数考虑了"在状态s下，动作a相比平均有多好"
- 减少方差：优势函数比单样本回报更稳定

### 相比Vanilla PG的优势

| 方法 | 梯度估计 | 方差 |
|------|----------|------|
| Vanilla PG | G_t（单样本回报） | 高 |
| Actor-Critic | A^π(s_t, a_t)（价值估计） | 中-低 |

## 优势函数估计方法

### 1. 一步TD估计

```python
A^π(s_t, a_t) ≈ r_t + γ V^π(s_{t+1}) - V^π(s_t)
```

- **TD误差 δ_t**：时序差分误差
- **直觉**：r_t + γV(s_{t+1}) 是对 Q^π 的估计，减去 V(s_t) 得到优势
- **偏差-方差权衡**：
  - 低方差：只用一个样本估计
  - 可能有偏差：依赖价值函数估计

### 2. n步回报

```python
A_t = Σ_{k=0}^{n-1} γ^k r_{t+k} + γ^n V^π(s_{t+n})
```

| n值 | 名称 | 方差 | 偏差 |
|-----|------|------|------|
| n=1 | TD(1) | 低 | 有 |
| n=∞ | Monte Carlo | 高 | 无 |
| n∈[2,∞) | n步TD | 中 | 介于两者之间 |

### 3. λ回报（TD-λ）

```python
A_t = (1-λ) Σ_{n=1}^∞ λ^{n-1} · n步回报
```

- **λ=0**：等同于TD(1)，低方差高偏差
- **λ=1**：等同于蒙特卡洛，高方差无偏差
- **λ∈[0.9, 0.99]**：实践中常见的选择，平衡偏差和方差

## 价值函数拟合（Value Function Fitting）

### 训练数据构建

```python
# 对每个 (s_t, a_t)，目标是从t开始的实际回报

# 蒙特卡洛目标（无偏但高方差）
y_t = Σ_{k=t}^T r_k

# TD(λ)目标（加权平均）
y_t = Σ_{k=0}^{∞} (λγ)^k δ_{t+k}
```

### 监督学习框架

```python
# 拟合价值网络 V_φ(s)
min_φ Σ_t ||V_φ(s_t) - y_t||²

# 类似监督学习，但目标 y_t 是由环境交互得到的
```

### 价值网络架构

- **输入**：状态 s（可以是原始观测或特征）
- **输出**：标量价值 V(s)
- **常见架构**：MLP、CNN（图像输入）、RNN（序列输入）

## 完整演员评论家算法

```
1. 用 π_θ 收集 trajectories（环境交互）
2. 对每个时间步计算回报目标 y_t
   - 方法1：蒙特卡洛 y_t = Σ_{k=t}^T r_k
   - 方法2：TD(λ) y_t = r_t + γ V(s_{t+1})
3. 更新价值网络 V_φ：min_φ Σ ||V_φ(s_t) - y_t||²
4. 计算优势估计 Â_t = r_t + γ V_φ(s_{t+1}) - V_φ(s_t)
5. 更新策略：∇_θ J ≈ Σ_t ∇_θ log π_θ(a_t|s_t) · Â_t
```

### 两个网络 vs 共享网络

| 架构 | 优点 | 缺点 |
|------|------|------|
| 两个独立网络 | 专业化 | 参数不共享，计算量大 |
| 共享骨干网络 | 参数共享，样本效率高 | 需要权衡两个loss |

## 折扣因子（Discount Factor）再探

### 问题

长轨迹中价值估计会变得很大：

```python
V(s) = r + γr + γ²r + ... = r / (1-γ)
# 如果 r=1, γ=0.99：V ≈ 100
# 如果 r=1, γ=0.999：V ≈ 1000
```

### 折扣的语义解释

**折扣因子 γ 相当于每步有 (1-γ) 概率"终止"当前轨迹**

```python
A_t = r_t + γ V(s_{t+1}) - V(s_t)
```

- **实际效果**：折扣使得远处的奖励对当前决策的影响减弱
- **直觉**：动作对远期结果的影响不确定性更高，应该打折

### 折扣与方差的关系

| γ 值 | 未来奖励权重 | 有效视野 | 方差 |
|------|-------------|----------|------|
| γ=0.9 | 快速衰减 | 短 | 低 |
| γ=0.99 | 缓慢衰减 | 长 | 中 |
| γ=0.999 | 几乎不衰减 | 很长 | 高 |

**实践建议**：γ=0.99 是常见且有效的选择

## 偏差-方差权衡总结

| 估计方法 | 方差 | 偏差 | 样本效率 | 收敛速度 |
|----------|------|------|----------|----------|
| 蒙特卡洛 | 高 | 无 | 低 | 慢 |
| TD(1) | 低 | 有 | 高 | 快 |
| TD(λ) | 中 | 中 | 中 | 中 |
| GAE | 可调 | 可调 | 高 | 快 |

**GAE（广义优势估计）**：λ 参数的推广，可以精细调节偏差-方差平衡

### 实践中的GAE设置

```python
# GAE(γ, λ) 公式
A_t^{GAE} = Σ_{k=0}^{∞} (γλ)^k δ_{t+k}

# 推荐参数
γ = 0.99   # 折扣因子
λ = 0.95   # GAE参数
```

## Actor-Critic的局限性

| 问题 | 描述 | 解决方案 |
|------|------|----------|
| **价值函数过拟合** | 价值估计不准导致策略误导 | 目标网络、延迟更新 |
| **Bootstrapping偏差传播** | TD目标依赖的价值函数不准会传播错误 | 多次采样平均 |
| **初始化敏感** | 价值网络初始化影响训练稳定性 | 合理初始化 |
