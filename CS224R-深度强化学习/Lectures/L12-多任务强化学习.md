# Stanford CS224R | 多任务强化学习 | 第 12 讲

## 核心问题

- **多任务 RL**：一个智能体学习完成多个不同任务
- **核心挑战**：任务间的负迁移（negative transfer）、表示冲突、梯度干扰
- **目标**：在任务间共享表示，同时保持任务特定的能力

## 任务定义与表示

- **任务形式化**：$\tau = (S, A, p_0, p(s'|s,a), H, r(s,a))$ — 每个任务有不同奖励函数或动力学
- **任务嵌入（task embedding）**：用向量 $\psi$ 编码任务身份信息
- **Goal-conditioned RL**：任务 = 目标状态 $g$，奖励 $r = \mathbb{1}_{s=g}$

| 任务类型 | 表示方式 | 学习信号 |
|----------|----------|----------|
| 目标达成 | $r = f(s, g)$ | sparse 或 dense |
| 指令跟随 | $r = f(text, s)$ | reward model |
| 技能组合 | $r = f(skill_1, skill_2)$ | composite |

## 共享表示学习

- **参数共享**：不同任务策略共享部分神经网络
  - 共享编码器（encoder），任务特定解码器（decoder）
  - 硬共享 vs 软共享
- **表示学习**：学一个任务无关的表示 $z$，使得 $p(\text{task} | z)$ 容易区分

```
共享编码器架构：
s → Encoder(s) → z → [Task1头(z), Task2头(z), ...]
```

## 辅助任务与表示正则化

- **辅助任务（auxiliary tasks）**：增加额外损失函数来规范表示
  - 前向/反向动力学预测：$p(s_{t+1}|z_t, a_t)$ 和 $p(z_t|s_t)$
  - 对比学习：区分正负样本任务
- **表示一致性**：同一任务的不同状态应该有相似表示

## 策略蒸馏

- **从大模型蒸馏到小模型**：teacher 策略（单任务 expert）→ student 策略（多任务）
- **DAgger（Dataset Aggregation）**：迭代收集 teacher 演示数据，训练 student
- **行为克隆 vs 在线蒸馏**：行为克隆简单但会累积误差；在线蒸馏允许 student 交互

## 梯度冲突与解决方案

- **梯度冲突**：不同任务对同一参数求导方向相反
- **Magical（Google）方法**：用任务嵌入调制（modulate）网络权重，学习任务特定的权重调整
- **PEARL**：变分推断学习任务嵌入，用 posterior 聚合任务信息

## 多任务评估指标

| 指标 | 含义 | 理想值 |
|------|------|--------|
| Average return | 所有任务平均性能 | 高 |
| Success rate | 成功率 | 高 |
| Inter-task variance | 任务间性能差异 | 低 |
| Negative transfer | 相对单任务是否下降 | 无 |

## 实战注意事项

- **课程学习（curriculum learning）**：从简单任务逐步引入困难任务
- **任务抽样策略**：均匀抽样、优先抽样、基于多样性的抽样
- **经验 replay**：多任务下需要分任务的 replay buffer
