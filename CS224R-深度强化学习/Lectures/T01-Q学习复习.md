## MDP基础与核心概念

### MDP定义

**马尔可夫决策过程（MDP）** 由五元组定义：

```
MDP = (S, A, P(s'|s,a), R(s,a), γ)

其中：
├── S  : 状态空间
├── A  : 动作空间  
├── P  : 转移概率函数 P(s'|s,a)
├── R  : 奖励函数 R(s,a) 或 R(s,a,s')
└── γ  : 折扣因子 γ ∈ [0,1]
```

### 核心价值函数

| 函数 | 符号 | 定义 | 条件 |
|-----|-----|------|-----|
| **价值函数** | V^π(s) | 从状态s开始遵循策略π的期望累计折扣奖励 | 仅条件于状态s |
| **Q函数** | Q^π(s,a) | 从状态s执行动作a后遵循策略π的期望累计折扣奖励 | 条件于(s,a) |
| **最优Q函数** | Q*(s,a) | 所有策略中最大的Q值 | 无π |

**三者的数学关系：**

```python
# 价值函数是Q函数在策略π下的期望
V^π(s) = E_{a~π(·|s)}[Q^π(s,a)]
         = ∑_{a} π(a|s) · Q^π(s,a)

# 最优价值函数与最优Q函数的关系
V*(s) = max_a Q*(s,a)

# 最优策略 = 在每个状态选择Q值最大的动作
π*(s) = argmax_a Q*(s,a)
```

### Advantage函数

**优势函数**衡量某个动作相对于策略平均水平的优势：

```
A^π(s,a) = Q^π(s,a) - V^π(s)
```

- A > 0：该动作优于策略平均 → 策略应更频繁选择
- A = 0：策略选择的动作（对于最优策略所有动作A=0）
- A < 0：该动作劣于策略平均

## Bellman方程与动态规划

### Bellman最优方程

**Q函数的Bellman最优方程：**

```
Q*(s,a) = E[R(s,a) + γ · max_{a'} Q*(s', a')]
         = ∑_{s'} P(s'|s,a) · [R(s,a) + γ · max_{a'} Q*(s',a')]
```

**价值函数的Bellman最优方程：**

```
V*(s) = max_a E[R(s,a) + γ · V*(s')]
       = max_a ∑_{s'} P(s'|s,a) · [R(s,a) + γ · V*(s')]
```

### 迭代求解：Q-Learning

**核心思想：从任意初始Q值出发，通过迭代逐步逼近真值**

```python
# Q迭代算法（动态规划）
Q_{k+1}(s,a) = ∑_{s'} P(s'|s,a) · [R(s,a) + γ · max_{a'} Q_k(s',a')]

# 在tabular环境下，从terminal states反向传播
# 迭代直到收敛 → Q* ≈ Q_∞
```

**Grid World示例：** 5个动作（上下左右+停留）

| 迭代轮次 | 状态更新行为 |
|---------|------------|
| k=0 | Q初始化为0（terminal states除外） |
| k=1 | Terminal state获得值，开始传播 |
| k=2,3,... | 值从goal反向传播到所有状态 |
| 收敛 | Q*(s,a) = 最短路径的折扣奖励 |

### 为什么需要Q函数而非仅策略？

| 方法 | 优点 | 缺点 |
|-----|------|-----|
| **纯策略方法（Policy Gradient）** | 直接优化策略 | 高方差，sample效率低 |
| **Q函数辅助** | 将环境方差转化为偏置，降低方差 | 需要额外学习Q函数 |
| **动态规划** | 样本效率高（利用环境模型） | 依赖完美环境模型 |

## Tabular到Parametric：Fitted Q-Learning

### 为什么需要函数近似？

**Tabular Q-Learning的问题：**
- 状态空间连续 → 无数Q值需要存储
- 状态空间高维（图像）→ 无法tabular存储
- 无法泛化到未见状态

**函数近似的优势：**

```
平滑性假设：相近状态 → 相近Q值
→ 神经网络可以泛化
```

### 两种Q函数参数化

| 类型 | 输入 | 输出 | 适用场景 |
|-----|------|------|---------|
| **Continuous Q** | (s, a) | Q(s,a) ∈ R | 连续动作空间 |
| **Discrete Q** | s | 向量 [Q(s,a_1), ..., Q(s,a_n)] | 离散动作空间（枚举） |

**Continuous Q的劣势：**
- 计算max时需要采样估计 → 估计有方差
- 离散动作可精确计算max → 无偏

## TD学习 vs Monte Carlo vs n-Step Return

### 三种估计目标

**从价值函数定义推导：**

```python
# Monte Carlo估计（无偏但高方差）
# V(s) = E[∑_{k=0}^{∞} γ^k r_{t+k} | s_t = s]
G_t = ∑_{k=0}^{T-t} γ^k r_{t+k}

# TD(1)估计（低方差但有偏）
# 利用当前价值函数估计未来价值
y_t = r_t + γ · V(s_{t+1})

# n-Step Return（trade-off）
# G_t^{(n)} = ∑_{k=0}^{n-1} γ^k r_{t+k} + γ^n · V(s_{t+n})
```

### Bias-Variance Trade-off

| 方法 | Bias | Variance | 特点 |
|-----|------|----------|-----|
| **Monte Carlo** | 无偏（unbiased） | 高方差（full horizon噪声累积） | 完全依赖实际采样 |
| **TD(1)** | 有偏（价值函数可能不准） | 低方差（只看1步） | 用近似替代真实 |
| **n-Step** | 随n增大bias减小 | 随n增大variance增大 | 居中trade-off |

### Dynamic Programming的Stitching能力

**关键优势：动态规划可以"缝合"不同轨迹片段**

```
轨迹1：A → B（但未能到C）
轨迹2：C → D（成功）

通过1步TD_backup：
→ 已知B的Q值 + B的下一状态是C
→ 可以推断A → C的路径价值
→ 无需完整轨迹A→D
```

**vs 纯Monte Carlo：**
- Monte Carlo需要完整的A→D轨迹才能估计A的价值
- 动态规划通过stitching更高效地利用数据

## 半梯度（Semi-Gradiant）与目标网络（Target Network）

### TD学习的梯度问题

**Naive TD update的问题：**

```python
# Q_approx(s', a*) 中的a*依赖于当前Q_approx
# 若传递梯度 → 优化目标随参数变化 → 训练不稳定
y = r + γ · max_a Q_approx(s', a; θ)  # max在左边也在右边
loss = (Q_approx(s,a; θ) - y)²  # 双重梯度问题
```

### Semi-Gradiant Solution

**关键洞察：不在目标侧传递梯度**

```python
# 正确做法：冻结目标侧参数
y = r + γ · max_a Q_target(s', a)  # Q_target不更新

loss = (Q_approx(s,a; θ) - y)²
# 只在Q_approx侧传递梯度
```

### 目标网络（Target Network）

| 策略 | 描述 | 更新频率 |
|-----|------|--------|
| **Hard Target Update** | 每N步直接复制θ到θ' | 较低（如每1000步） |
| **Soft Update (Polyak)** | EMA平滑更新θ' | 每步，系数τ（如0.99） |

```python
# Polyak Averaging（推荐）
θ' ← τ · θ' + (1-τ) · θ
# 通常τ=0.99，缓慢跟随主网络
```

### 完整训练循环

```python
for iteration in range(N):
    # 1. 采样transition
    (s, a, r, s') = replay_buffer.sample()
    
    # 2. 计算TD target（stop gradient）
    with torch.no_grad():
        y = r + γ · max_a Q_target(s', a)
    
    # 3. 更新Q网络（gradient descent）
    loss = mse(Q_online(s,a), y)
    loss.backward()
    
    # 4. 定期更新target网络
    if iteration % target_update_freq == 0:
        θ_target = τ * θ_target + (1-τ) * θ_online
```

## 实用技巧

### 梯度裁剪（Gradient Clipping）

**问题：TD误差可能导致梯度爆炸**

| 现象 | 影响 |
|-----|------|
| 梯度太大 | 更新步长过大，训练震荡 |
| 长期大梯度 | 策略崩溃 |

**解决：**

```python
torch.nn.utils.clip_grad_norm_(parameters, max_norm=1.0)
```

### Huber Loss（平滑L1 Loss）

**问题：MSE对异常值（outliers）过于敏感**

```
Huber Loss = {
    0.5 · (y - ŷ)²                    if |y - ŷ| ≤ δ
    δ · |y - ŷ| - 0.5·δ²             otherwise
}
```

| 特性 | 说明 |
|-----|------|
| 当预测接近目标时 | 表现为L2 Loss，精细调整 |
| 当预测远离目标时 | 表现为L1 Loss，对异常值鲁棒 |

## Experience Replay（经验回放）

### 为什么需要Replay Buffer

**时序相关的采样问题：**
- 连续transition高度相关
- 直接采样导致过拟合近期经验
- 在线策略更新需要独立同分布采样

**Replay Buffer结构：**

```python
Buffer = [(s,a,r,s'), (s,a,r,s'), ...]  # 存储transitions而非trajectories

# 采样时打破时序
batch = random.sample(buffer, batch_size)
```

### 优势

| 优势 | 说明 |
|-----|------|
| **打破时序相关性** | 可跨trajectory随机采样 |
| **避免Recency Bias** | 不让当前策略主导数据分布 |
| **样本高效利用** | 每条经验可被多次使用 |
| **支持Off-policy** | 任意历史经验均可使用 |

### 设计考量

| 参数 | 典型设置 |
|-----|---------|
| Buffer大小 | 10^5 ~ 10^6（内存决定） |
| 采样策略 | 均匀随机（可扩展到优先级采样） |
| RNN历史 | 可用Transformer架构处理长历史 |

## Q-Learning的Overestimation问题

### 问题根源：Max Operator

**数学分析：**

```
假设：Q_approx(s', a) = Q_true(s', a) + ε
其中 ε ~ N(0, σ²)（均值为0的噪声）

E[max_a Q_approx(s', a)] ≥ max_a E[Q_approx(s', a)]
                              = max_a Q_true(s', a)
```

**关键洞察：**
- 即使噪声均值为0，max操作也会导致**正偏移**
- 噪声越大，overestimation越严重
- 多步迭代后，误差会在整个状态空间累积

### Overestimation的后果

| 影响 | 说明 |
|-----|------|
| 策略退化 | 选择被高估的次优动作 |
| 误差传播 | 错误值会扩散到临近状态 |
| 训练不稳定 | Q值持续膨胀（escalation） |

### 可视化案例

```
Q-learning的Q值在迭代后会出现大误差棒（Error Bar）
特别在高噪声环境或长horizon任务中明显
```

## Double Q-Learning：解决Overestimation

### 核心思想

**问题：用同一组参数同时估计值并选择最大值 → 噪声叠加**

**解决：用两套独立Q网络解耦选择与估计**

```python
# Double Q-Learning更新
# 1. 用Online网络选择最大值动作
a_max = argmax_a Q_online(s', a)

# 2. 用Target网络评估该动作的值
y = r + γ · Q_target(s', a_max)

# 3. 更新Online网络朝y靠近
```

**效果：**
- 选择动作时：用online的估计（倾向选择被overestimate的动作）
- 但估计值时：用target的参数（独立噪声）
- 两者噪声独立 → overestimation减轻

### 与Ensemble的关系

| 方法 | Ensemble大小 | 效果 |
|-----|-------------|------|
| **Double Q** | 2 | 显著改善overestimation |
| **更多Ensemble** | >2 | 对Offline RL更关键（分布偏移更严重） |

**Offline RL场景：**
- 分布偏移（distribution shift）更严重
- 需要更大ensemble（如EDAC、SaKaen等使用10+）
- 用min而非avg作为target（学习underestimate更安全）

## 总结对比表

| 概念 | 核心公式 | 要点 |
|-----|---------|------|
| V^π(s) | E[∑γ^k r_{t+k}] | 仅条件于状态 |
| Q^π(s,a) | E[R(s,a)+γV^π(s')] | 条件于状态-动作对 |
| A^π(s,a) | Q^π(s,a) - V^π(s) | 相对优势 |
| Bellman Optimal | Q* = max_π Q^π | 迭代求解 |
| TD Target | y = r + γ·V(s') | 单步Bootstrap |
| n-Step | G^{(n)} = Σγ^k r_{t+k} + γ^n V(s_{t+n}) | Bias-Variance trade-off |
| Semi-Gradiant | stop gradient on target | 稳定训练 |
| Replay Buffer | 存储transitions | 打破时序相关 |
| Double Q | 用两套网络 | 缓解overestimation |

## 推荐实现路径

```python
# 1. 定义Q网络（Continuous或Discrete）
Q_network = MLP(state_dim, action_dim)

# 2. 目标网络初始化
Q_target = copy(Q_network)

# 3. Replay Buffer初始化
buffer = ReplayBuffer(capacity=100000)

# 4. 训练循环
for step in range(total_steps):
    # 采集数据（ε-greedy）
    action = epsilon_greedy(Q_network, state)
    next_state, reward = env.step(action)
    buffer.push(state, action, reward, next_state)
    
    # 随机采样batch
    batch = buffer.sample(batch_size)
    
    # Double Q计算target
    with torch.no_grad():
        a_max = Q_online(batch.next_state).argmax(dim=1)
        y = batch.reward + γ * Q_target(batch.next_state, a_max).squeeze()
    
    # TD loss + optimizer step
    loss = mse(Q_online(batch.state, batch.action), y)
    optimizer.zero_grad()
    loss.backward()
    # gradient clipping
    torch.nn.utils.clip_grad_norm_(Q_network.parameters(), 1.0)
    optimizer.step()
    
    # 定期更新target网络
    if step % target_update_freq == 0:
        hard_update(Q_target, Q_online)  # 或soft update
```
