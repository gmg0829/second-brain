## 离线策略学习动机

### On-Policy的问题

**每批数据只能用一次**：样本效率极低

```
Vanilla Actor-Critic（On-Policy）：
1. 用当前策略 π_θ 收集数据
2. 更新策略
3. **旧数据丢弃！** 必须重新收集
```

- **样本效率低**：需要大量环境交互
- **成本高**：机器人、真实世界场景中交互代价昂贵
- **训练慢**：每次迭代都要重新收集数据

### 解决方向

**复用旧数据**：使用**重要性采样**（Importance Sampling）修正分布偏移

## 重要性采样（Importance Sampling）

### 修正概率比

```python
# 目标：从 π_θ 采样轨迹，但只有 π_old 的数据
w_t = π_θ(a_t|s_t) / π_old(a_t|s_t)
```

- **π_old**：生成数据的旧策略
- **π_θ**：当前要更新的策略
- **w_t**：修正两个策略之间概率差异的权重

### 离线策略梯度

```python
# 用重要性采样修正梯度
∇_θ J ≈ Σ_t w_t · ∇_θ log π_θ(a_t|s_t) · A_t
```

### 核心问题：策略变化大时梯度不稳定

```python
# 当 π_θ 和 π_old 差距很大时
w_t = π_θ(a|s) / π_old(a|s) 可能变得极大或极小

示例：
- π_old(a|s) = 0.01
- π_θ(a|s) = 0.99
- w = 99  （极大！）

# 梯度会被极端权重主导
∇_θ J ≈ w_t · ∇_θ log π_θ(a|s) · A_t  → 爆炸或消失
```

**问题本质**：off-policy时策略变化可能很大，重要性权重变得极不稳定

## PPO：限制策略变化

### 核心思想

**限制每次更新中策略偏离旧策略的程度**

### 方法1：KL约束（TRPO）

```python
J̃(θ) = J(θ) - β · KL(π_old || π_θ)

# β 是超参数，控制允许的策略变化程度
# 新策略太远离旧策略会受惩罚
```

- **KL散度**：衡量两个概率分布的差异
- **优点**：有理论保证（信任域）
- **缺点**：需要额外的KL计算，实现复杂

### 方法2：截断重要性权重（PPO-Clip）

```python
w_t = clip(π_θ(a_t|s_t) / π_old(a_t|s_t), 1-ε, 1+ε)

# ε ≈ 0.2：典型值
# 重要性权重被截断，不允许过大变化
```

**Clip机制**：
```
如果 w > 1+ε：截断为 1+ε
如果 w < 1-ε：截断为 1-ε
只保留 [1-ε, 1+ε] 范围内的权重
```

## PPO代理目标函数（Surrogate Objective）

```python
L^{CLIP}(θ) = E_t [ min(
    w_t · A_t,                    # 未截断的IS目标
    clip(w_t, 1-ε, 1+ε) · A_t   # 截断后的目标
) ]
```

### 两个技巧的协同

| 技巧 | 作用 | 效果 |
|------|------|------|
| **权重裁剪** | 防止极端比例 | 限制策略变化幅度 |
| **取min** | 保证是下界 | 不会过度乐观 |

### Clip的直观理解

```python
# 当 A_t > 0（好动作）时：
- w_t > 1+ε：被截断为 1+ε，增加幅度受限
- w_t < 1+ε：保持原样

# 当 A_t < 0（坏动作）时：
- w_t < 1-ε：被截断为 1-ε，减少幅度受限
- w_t > 1-ε：保持原样

# 效果：防止策略变得太"自信"，稳定训练
```

## 广义优势估计（GAE）

### 多步TD的加权平均

```python
A_t^{GAE} = Σ_{k=0}^{∞} (γλ)^k δ_{t+k}

其中 δ_t = r_t + γ V(s_{t+1}) - V(s_t)  # TD误差
```

### λ参数的效果

| λ 值 | 等同于 | 方差 | 偏差 |
|-----|--------|------|------|
| λ=0 | TD(1)，一步 bootstrapping | 最低 | 有 |
| λ=1 | 蒙特卡洛，无 bootstrapping | 最高 | 无 |
| λ∈(0,1) | 介于两者之间 | 可调 | 可调 |

**典型值**：λ ∈ [0.9, 0.99] 在实践中效果较好

### GAE的直觉

```python
A_t^{GAE} = (1-λ)(δ_t + γλδ_{t+1} + γ²λ²δ_{t+2} + ...)

# 多种 bootstrapping 程度的加权平均
# λ 大 → 更接近蒙特卡洛
# λ 小 → 更接近TD
```

## 经验回放（Replay Buffer）

### On-Policy vs Off-Policy

| 类型 | 数据来源 | 样本效率 | 实现复杂度 |
|------|----------|----------|------------|
| **On-Policy** | 只用当前策略收集的数据 | 低 | 低 |
| **Off-Policy** | 重用历史数据 | 高 | 中 |

### Replay Buffer实现

```python
ReplayBuffer = []  # 经验回放缓冲区

for step in training:
    # 1. 用当前策略采样 transition
    a = π_θ(s)
    s', r = env.step(a)
    buffer.add((s, a, r, s'))
    
    # 2. 从 buffer 中采样 mini batch 更新
    batch = buffer.sample(batch_size=32)
    update_V_and_π(batch)
    
    # 3. 缓冲区可以存多条轨迹的数据
    # 4. 可以用均匀采样或优先级采样
```

### Buffer带来的问题

**Buffer中混合了不同策略的数据**：

```
Buffer内容：
- 策略π₁收集的数据（早期）
- 策略π₂收集的数据（中期）
- 策略π₃收集的数据（当前）

问题：用这些数据更新时，价值估计可能不准确
因为不同策略的"价值"含义不同
```

### 解决方案：优先经验回放（PER）

```python
# 优先级：TD误差越大的样本优先级越高
priority = |δ_t|
# 采样概率与优先级成正比
```

## Q函数 vs V函数选择

### 为什么Q函数更适合Off-Policy？

| 函数 | 直接学习目标 | Off-Policy适用性 |
|------|-------------|-----------------|
| V(s) | E_{a~π}[Q(s,a)] | 需要知道动作分布 |
| Q(s,a) | r + γ E[V(s')] | 可直接从(s,a,r,s')学习 |

**关键洞察**：
- V^π(s) = E_{a~π(·|s)}[Q^π(s, a)] — 依赖于策略π的动作分布
- Q^π(s, a) = r + γ E[V(s')] — 不直接依赖π，可以独立学习

### 软更新（Soft Update）

```python
# 目标网络缓慢更新，避免大幅跳变
V_new ← (1-ρ) · V_old + ρ · target

# ρ 很小（如 0.001）
# 每次更新只移动一小步
# 类似指数移动平均
```

## PPO算法完整流程

### 实践中的PPO

```
1. 采样约2000时间步的 trajectories（用旧策略）
2. 用 GAE(γ, λ) 计算优势估计
3. 用 clip 代理目标更新策略（约10个epoch，mini batch更新）
4. 用 TD(λ) 更新价值函数（约10个epoch）
5. 旧策略 ← 新策略
6. repeat，约500次迭代
```

### 效果对比

| 方法 | 样本效率 | 超参数敏感度 | 训练稳定性 |
|------|----------|-------------|-----------|
| Vanilla PG | 低（数据用一次） | 中 | 中 |
| PPO | 高（约10倍提升） | 中（ε≈0.2） | 高 |
| TRPO | 高 | 高（KL约束） | 高 |
| 模仿学习 | 高（离线） | 低 | 中 |

### PPO的成功因素

1. **Clip机制**：简单有效，限制策略变化
2. **多epoch更新**：一次采样多次利用，提高样本效率
3. **GAE**：平衡偏差和方差的优势估计
4. **目标网络稳定**：价值函数更新平缓

## PPO vs 其他On-Policy方法对比

| 方法 | 策略约束方式 | 优点 | 缺点 |
|------|-------------|------|------|
| **Vanilla PG** | 无约束 | 简单 | 高方差，可能崩溃 |
| **TRPO** | KL散度约束 | 有理论保证 | 实现复杂，计算量大 |
| **PPO** | Clip截断 | 简单有效，计算高效 | 略逊于TRPO的理论保证 |
| **AWR** | 优势加权回归 | 稳定 | 需要计算优势 |

## Off-Policy Actor-Critic的挑战与解决方案

### 挑战1：分布偏移

```python
# 重要性权重可能极大或极小
w = π_θ(a|s) / π_old(a|s)
# 当两个策略差异大时，权重爆炸
```

**PPO解法**：Clip到 [1-ε, 1+ε]

### 挑战2：价值估计不准确

```python
# Buffer中混合了不同策略的数据
# 不同策略的Q值含义不同
# 用旧数据估计的价值不准确
```

**PPO解法**：
- 限制每次策略变化幅度
- 多次epoch更新让价值函数适应

### 挑战3：探索与利用的平衡

```python
# Off-Policy时：
# - Buffer有历史数据（多样性）
# - 但当前策略可能跟历史策略差异大
```

**解法**：保持一定比例的新数据，或使用Noisy探索
