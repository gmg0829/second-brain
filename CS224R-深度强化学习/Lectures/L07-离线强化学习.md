## 离线强化学习概述

- **离线强化学习(Offline Reinforcement Learning)**：从固定数据集中学习策略，无需与环境交互
  - 也称Batch RL或_dataset RL_，是RL的工业化部署形态
  - 数据来源：人类演示日志、规则引擎、昂贵实验的历史记录
  - 核心挑战：数据分布偏移（distributional shift）导致的OOD动作过估计
  - 优点：安全（无需在线探索）、可利用海量离线数据、适合真实世界部署

- **离线RL vs 其他范式**：在线交互学习的权衡取舍
  - **在线RL**：可交互探索，数据效率低，潜在危险（机器人可能损坏）
  - **模仿学习(Imitation Learning)**：模仿专家数据，简单但无法超越、无法自主探索
  - **离线RL**：从固定数据学习，可利用非专家数据，理论上可超越数据上限
  - **半在线RL**：agent可收集数据但需谨慎探索（KAIST等研究热点）

- **行为策略π_β**：生成离线数据集的策略，可能是人类或旧版agent
  - 数据集D = {(s_i, a_i, r_i, s'_i)}_{i=1}^N，来自π_β与环境交互
  - 离线数据质量决定学习上限：数据分布越广，学到的策略越强
  - 关键假设：s' ~ p(s'|s, a)，即环境转移概率已知或数据集覆盖充分

## 分布偏移问题

- **分布偏移(Distribution Shift)**：学习策略π_θ与数据策略π_β的动作分布不同
  - 形式化：对于某状态s，π_θ可能选择数据中未出现过的动作a
  - 这种动作称为"分布外动作(Out-of-Distribution, OOD)"
  - Q函数在OOD动作处产生任意错误值（过估计或欠估计）
  - Belleman算子对OOD动作的Q值误差会随迭代累积放大

- **过估计问题在离线下更严重**：离线数据无法纠正错误估计
  - 在线Q-learning：探索可发现并纠正过估计（访问OOD状态，获得真实奖励）
  - 离线Q-learning：一旦高估，会选择高估的OOD动作，但永远不会获得该区域数据来纠正
  - 结果：错误的OOD动作被选中，形成恶性循环，学到的策略严重退化

- **分布偏移的数学刻画**：
  - 数据分布：π_β生成的(s, a)分布，记为p_data(s, a)
  - 学习策略分布：π_θ生成的(s, a)分布，记为p_θ(s, a)
  - 偏移度量：D_KL(p_θ || p_data) 或其他散度度量
  - 当p_θ(s, a) << p_data(s, a)时（即π_θ很少选择数据中的动作），Q值不可靠

## 简单基线方法

- **行为克隆(Behavioral Cloning, BC)**：监督学习直接模仿数据中的动作
  - 损失函数：L(θ) = E_{(s,a)~D}[-log π_θ(a|s)]
  - 优点：简单、稳定、无需reward；缺点：无法利用reward信息、无法超越专家
  - 当数据中包含非最优轨迹时，BC会学到"平均"策略，可能很差
  - 关键发现：数据量足够大时，BC可接近最优（当数据覆盖所有好动作时）

- **过滤式模仿学习(Filtered Imitation Learning)**：只学习数据中的好轨迹
  - 第一步：评估轨迹质量（如返回总和、任务完成度）
  - 第二步：过滤出Top-k%最好的轨迹作为新数据集
  - 第三步：在过滤后数据上做行为克隆
  - 数学表达：D_good = {(τ, r) ∈ D : r > percentile(D, 70)}
  - 优点：自动从混合数据中提取好策略；缺点：需要轨迹质量信号
  - 适用场景：数据中好与差轨迹混杂（如人类演示中有失误）

- **优势加权回归(Advantage Weighted Regression, AWR)**：按优势加权的监督学习
  - 核心思想：数据中好的(state, action)应该有更高的权重
  - 优势估计：A(s, a) = Q(s, a) - V(s)（相对于平均动作的优势）
  - 策略更新：π_θ(a|s) ∝ exp(A(s, a) / t) · π_β(a|s)
  - 温度参数t控制探索程度：t小→更激进利用高优势动作，t大→更接近均匀
  - 等价于：加权监督学习，好动作高权重，差动作低权重
  - 算法流程：先用MC或TD估计V(s)，计算A(s,a)，然后加权BC

## 蒙特卡洛与TD优势估计

- **蒙特卡洛(MC)优势估计**：用完整episode回报估计真实优势
  - 上确界：E[G_t | s_t, a_t] ≈ Q(s_t, a_t)，无偏但方差大
  - G_t = r_t + γr_{t+1} + ... + γ^{T-t}r_T为实际累计折扣奖励
  - V(s) ≈ (1/N) Σ_i G_i(s)，多轨迹平均估计状态价值
  - 优点：无偏；缺点：单个episode方差大，需要多样本平均
  - 适用：episode较短、奖励噪声低的任务（如游戏）

- **TD优势估计**：用单步TD target估计，偏差低但有偏
  - A(s, a) ≈ r + γV(s') - V(s)
  - TD误差δ = r + γV(s') - V(s)即为TD优势估计
  - 偏差来源：V(s')是估计值而非真实值
  - 优点：低方差（单步估计）、样本效率高；缺点：有偏（V估计不准确时）

- **GAE(Generalized Advantage Estimation)**：可调偏差-方差权衡
  - GAE(λ)：加权平均无限多步TD误差
  - A^{GAE(λ)}_t = Σ_{l=0}^∞ (γλ)^l δ_{t+l}，δ_t = r_t + γV(s_{t+1}) - V(s_t)
  - λ=0：退化为TD(0)；λ=1：趋近MC（高方差）
  - λ∈[0.9, 0.99]是常用范围，平衡偏差与方差
  - 是PPO等算法的事实标准优势估计方法

## 保守Q学习(CQL)

- **CQL核心思想**：主动压低OOD动作的Q值，防止过度估计
  - 核心创新：在标准TD损失上增加额外项，惩罚高估的OOD Q值
  - 动机：离线RL的问题是OOD动作Q值不可靠→主动让它们变低
  - 理论基础：学到的策略价值不超过数据分布下最优策略的价值下界

- **CQL损失函数**：
  - 标准TD损失：L_critic(θ) = E[(Q(s, a; θ) - y)^2]
  - CQL额外项：α · [E_{a~π_θ}[Q(s, a)] - E_{a~π_β}[Q(s, a)]]
  - 第一项（期望最大化）：鼓励策略选择高Q值动作（可能导致OOD）
  - 第二项（数据期望最小化）：压低数据分布外动作的Q值
  - 两项结合：策略会在数据分布内寻求高Q值，避免OOD

- **CQL超参数α的作用**：
  - α=0：退化为标准DQN（可能过度估计）
  - α太大：策略被限制在数据分布内，无法有效提升
  - 调参建议：从0.1~1开始，根据OOD动作Q值分布调整
  - 自适应变体：自动调整α使策略约束在设定阈值内

- **CQL的理论保证**：
  - 在无限数据下，CQL学到的策略价值不低于真实最优策略减去数据覆盖误差
  - 具体：E_{s~d_π}[V(s)] ≥ E_{s~d_{π*}}[V(s)] - O(ε_{cov})
  - 误差ε_{cov}与数据对最优策略的支持程度相关
  - 这是离线RL第一个有实际意义理论保证的算法

## 隐式Q学习(IQL)

- **IQL核心思想**：用expectile回归绕过OOD过估计，而非显式约束
  - 观察：过估计源于对OOD动作取max——如果我们不取max呢？
  - IQL不学习显式策略，而是学习最优V*函数的估计
  - V*(s) = E_{a~π*(s)}[Q*(s, a)]，隐含着对动作分布的期望
  - 通过非对称损失函数，IQL估计"好动作的价值"而非"最好动作的价值"

- **Expectile回归**：非对称L2损失，比分位数更灵活
  - 标准L2损失：L_2(x) = (x)^2，对正负偏差同等惩罚
  - Expectile损失：L_τ(x) = |τ - 1_{x<0}| · x^2
  - τ ∈ (0, 1)为expectile水平：τ大→关注高值，τ小→关注低值
  - τ=0.5时退化为标准L2；τ→1时趋近于取最大值（max操作）
  - 对比：分位数回归用|τ - 1_{x<0}| · |x|（L1），expectile用平方（L2）

- **IQL的两阶段学习**：
  - **阶段1 - V函数学习**：用expectile回归学V(s) ≈ E_{好动作}[Q(s, a)]
    - 损失：L_V(ψ) = E_{(s,a,r,s')~D}[L_τ(r + γV_ψ(s') - V_ψ(s))]
    - expectile参数τ设大（如0.9）→学到偏高的V值（近似top-k%好动作的平均）
  - **阶段2 - Q函数学习**：用V(s)作为target学Q(s, a)
    - 损失：L_Q(θ) = E_{(s,a,r,s')~D}[(r + γV_ψ(s') - Q_θ(s, a))^2]
    - Q值更新只用数据中实际出现的(s, a)，避免OOD
  - **隐式策略提取**：从V和Q中隐式导出策略
    - 动作概率：π(a|s) ∝ exp((Q(s, a) - V(s)) / T)
    - T为温度：T小→策略sharp（只选最高Q动作），T大→更均匀
    - 不需要单独的策略网络，策略隐式定义在V/Q中

- **IQL vs CQL对比**：
  - CQL显式约束策略（KL或Q值惩罚），IQL隐式通过expectile回避问题
  - IQL不需要额外超参数α（自动从数据学习τ），更易调参
  - CQL需要知道数据分布π_β，IQL不需要（直接用数据中出现的动作）
  - 两者在大多数离线RL基准上性能相当，IQL在高维任务（机器人）上更好

## 离线RL的实践考量

- **D4RL基准**：离线RL的标准评测基准
  - **Ant、HalfCheetah、Walker**：MuJoCo locomotion任务
  - **Kitchen**：真实机器人厨房操控任务
  - **Adroit**：Shadow Hand机器人操作（写字、开门等）
  - 数据类型：random policy数据、medium policy数据、medium-expert混合数据
  - 评估指标：Normalized score = 100 × (学到的 - random) / (expert - random)

- **RT-1机器人数据**：大规模真实机器人遥操作数据
  - 来自13个机器人在办公室厨房环境中的13万条演示
  - 任务：抓取、放置、开抽屉等日常操控
  - 数据质量：混合了专家演示和辅助机器人采集的数据
  - 离线RL在RT-1数据上学到的策略泛化到新物体/场景

- **数据质量判断的三个维度**：
  - **多样性**：数据是否覆盖各种状态和动作——多样性低→无法学会对应对
  - **动作覆盖**：每个状态是否有多个可选动作——覆盖少→策略受限
  - **奖励标注准确性**：轨迹质量标签是否准确——标注错误→学习被误导

## 常见问题与解决

- **过估计问题**：策略与数据策略差异大时，Q值在OOD处爆炸
  - 症状：训练初期学到的策略看似有效，后期突然崩溃
  - 解决：使用CQL、IQL等保守方法，或降低学习率、减小策略更新幅度

- **数据不足**：离线数据无法覆盖所有可能情况
  - 症状：策略在数据覆盖区域表现好，OOD区域行为不可预测
  - 解决：使用更保守的策略约束，或收集更多样化的离线数据

- **因果混淆(Causal Confusion)**：模仿学习中的核心问题
  - 原因：数据中某些动作与成功有相关性但非因果
  - 例子：专家总是先抬手再抓取——BC可能学到抬手而非抓取
  - 解决：用干预数据打断虚假相关性，或用RL利用真实奖励

## 算法对比总结

| 算法 | 核心方法 | OOD处理 | 优点 | 缺点 |
|------|----------|---------|------|------|
| **BC** | 监督学习 | 无 | 简单稳定 | 无法超越数据 |
| **过滤式IL** | 数据过滤+BC | 间接 | 自动提取好数据 | 依赖轨迹质量信号 |
| **AWR** | 优势加权BC | 无 | 利用reward信号 | 仍是监督学习 |
| **CQL** | Q值惩罚 | 主动压低 | 理论保证 | 需调参α |
| **IQL** | Expectile回归 | 隐式回避 | 无需OOD惩罚项 | 实现较复杂 |
