# Stanford CS224R | 策略梯度 | 第3讲

## 在线强化学习流程

**核心循环**：收集数据→估计梯度→更新策略→重复

```
1. 初始化策略 π_θ
2. 用当前策略收集 trajectories {τ₁, τ₂, ..., τₙ}
3. 使用收集的数据估计梯度 ∇_θ J(θ)
4. 更新策略：θ ← θ + α · ∇_θ J(θ)
5. repeat 直到收敛
```

- **On-Policy**：每次更新只使用当前策略收集的数据
- **样本效率低**：旧策略的数据无法复用，必须重新收集

## 策略梯度定理

### 目标函数

**maximize期望累计奖励**

```python
J(θ) = E_{τ~p_θ(τ)} [ Σ_t r(s_t, a_t) ]
```

- τ ~ p_θ(τ)：轨迹由当前策略生成
- Σ_t r(s_t, a_t)：轨迹上的累计奖励

### 核心困难

**无法直接对采样过程求导**——p_θ(τ) 是一个由策略定义的高度非线性函数

## Log导数技巧（Log-Derivative Trick）

### 恒等式

```python
∇_θ p_θ(τ) = p_θ(τ) · ∇_θ log p_θ(τ)
```

- **证明**：利用对数求导法
  ```python
  ∇_θ log p_θ(τ) = ∇_θ p_θ(τ) / p_θ(τ)
  → ∇_θ p_θ(τ) = p_θ(τ) · ∇_θ log p_θ(τ)
  ```

### 策略梯度推导

```python
∇_θ J(θ) = E_{τ~p_θ(τ)} [ Σ_t ∇_θ log π_θ(a_t|s_t) · R(τ) ]
```

其中 R(τ) = Σ_t r(s_t, a_t) 是轨迹总奖励

**直觉理解**：
- 奖励高的轨迹 → 增加其中所有动作的概率
- 奖励低的轨迹 → 减少其中所有动作的概率
- **对数梯度** log π_θ(a|s) 告诉我们"如何调整动作概率"

## 仅使用未来奖励（因果性）

### 因果性原理

**动作 a_t 只影响 t 时刻之后的奖励**，不依赖于 t' < t 时刻的奖励

```python
∇_θ J(θ) = E_{τ~p_θ(τ)} [ Σ_t ∇_θ log π_θ(a_t|s_t) · Σ_{t'=t}^T r_{t'} ]
```

- **t 时刻之前的奖励不参与梯度计算**
- **更准确地关联动作与结果**：避免用t之前的"未来奖励"误导当前动作
- **减少方差**：减少每步参与计算的信息量

### 回报（Return）与优势（Advantage）

```python
G_t = Σ_{t'=t}^T r_{t'}    # 从t开始的累计未来奖励（Return）
A_t = G_t - b               # 减去baseline的优势
```

## Baseline（基线）

### 问题

所有奖励可能都是正的或负的，导致：
- 梯度方向不稳定
- 所有动作概率同方向变化
- 收敛慢

### 解决：减去Baseline

```python
∇_θ J(θ) = E_{τ~p_θ(τ)} [ Σ_t ∇_θ log π_θ(a_t|s_t) · (Σ_{t'=t}^T r_{t'} - b) ]
```

- **不改变期望**：baseline b 是常数，E[∇ log π · b] = 0
- **降低方差**：减去均值后，梯度方向更稳定

### 最优Baseline（理论最优）

**目标**：最小化梯度估计的方差

```python
b* = E[(∇ log π)² · R] / E[(∇ log π)²]
```

- 这是一个加权平均，最优 baseline 是奖励的加权均值
- **权重是梯度大小的平方**

### 实践中的Baseline选择

| Baseline类型 | 公式 | 方差降低效果 | 计算成本 |
|--------------|------|-------------|----------|
| 零基线 b=0 | 无 | 无 | 无 |
| 均值基线 | b = mean(R) | 中等 | 低 |
| 状态价值基线 | b = V^π(s_t) | 最好 | 中等 |
| 最优解析基线 | 上述加权公式 | 理论最优 | 高 |

**常用baseline**：平均奖励 = mean(Σ_t r_t) 对所有轨迹

## 算法总结：Vanilla策略梯度 / REINFORCE

### 完整算法

```python
for iteration:
    1. 用当前策略 π_θ 收集 n 条 trajectories
    2. for 每条 trajectory 的每个时间步 t:
        G_t = Σ_{t'=t}^T r_{t'}      # 回报（从t到最后的累计奖励）
        G_t -= b                      # 减去 baseline
        ∇_θ J += ∇_θ log π_θ(a_t|s_t) · G_t
    3. θ ← θ + α · ∇_θ J             # 更新策略参数
```

### 核心公式速查

| 概念 | 公式 | 说明 |
|------|------|------|
| 策略梯度 | ∇_θ J = E[∇θ log π(a\|s) · G] | 增加好动作概率 |
| 因果性 | G_t = Σ_{t'=t}^T r_{t'} | 只用未来奖励 |
| Baseline | G_t -= b | 减少方差 |
| 优势估计 | A_t = G_t - V(s_t) | 最优baseline |

## 实现细节

### 代理目标函数（Surrogate Objective）

```python
L(θ) = Σ_t log π_θ(a_t|s_t) · A_t
```

- **可直接用autograd优化**：PyTorch/TensorFlow自动求导
- **计算效率高**：一次前向 + 一次反向，而非多次
- **替代真实梯度**：用采样估计期望

### 策略表示

| 动作类型 | 分布形式 | 损失函数 | 示例 |
|----------|----------|----------|------|
| 离散动作 | Categorical π(a\|s) | 交叉熵损失 | Atari游戏（上下左右） |
| 连续动作 | 高斯 π(a\|s) = N(μ(s), σ²) | 负对数似然 | 机器人关节控制 |

- **离散**：策略网络输出每个动作的logits，用softmax得到概率
- **连续**：网络输出均值μ和方差σ，用重参数化采样

## 方差与挑战

### 偏差-方差权衡

| 方法 | 方差 | 偏差 | 样本效率 |
|------|------|------|----------|
| 蒙特卡洛（完整回报 G_t） | 高 | 无 | 低 |
| 一步 bootstrapping | 低 | 有（估计偏差） | 高 |
| n步回报 | 中 | 介于两者之间 | 中 |

- **蒙特卡洛**：G_t 是真实回报的无偏估计，但方差高
- **Bootstrapping**：用价值估计替代部分回报，减少方差但引入偏差
- **n步**：在两者之间权衡

### 策略梯度局限性

| 问题 | 描述 | 解决方案 |
|------|------|----------|
| **高方差** | 需要大量样本才能估计准确梯度 | Baseline、Actor-Critic |
| **Sparse奖励困难** | 几乎没有学习信号 | Reward Shaping、HER |
| **对奖励尺度敏感** | 不同任务奖励尺度差异大 | 奖励归一化 |
| **On-Policy限制** | 样本不能用多次 | Off-Policy、PPO |

### 高方差的具体表现

```
示例：机器人走迷宫
- 单条轨迹：可能需要1000步，其中999步都是0奖励
- 最后一步到达目标得到+1
- 策略梯度会把前999步的所有动作都视为"好"（因为总奖励为正）
- 但实际上只有最后几步真正重要
```

**解决方向**：
1. 更好的优势估计（Actor-Critic，降低方差）
2. 更好的baseline（状态价值，更精确的基准）
3. 信任区域（TRPO/PPO，限制更新幅度）
