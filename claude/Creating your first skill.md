## 简介 / Introduction

Build a personal skill that teaches Claude how to write PR descriptions in a consistent format and learn how they work.
构建一个个人技能，教 Claude 如何以一致的格式编写 PR 描述，并了解它们是如何工作的。

---

## 本课内容 / Lesson Content

### 创建第一个技能 / Creating Your First Skill

**目标 / Goal:**
- 教 Claude 如何编写 PR（Pull Request）描述
- 使用一致的格式
- 理解技能的工作原理

### 技能定义 / Skill Definition

**什么是技能 / What is a Skill:**
- 一组指令，告诉 Claude 如何执行特定任务
- 可以重复使用
- 在相关场景自动触发

### 示例：PR 描述技能 / Example: PR Description Skill

**输入 / Input:**
- PR 的更改内容
- 相关的问题或issue

**输出 / Output:**
- 一致的 PR 描述格式
- 包含：概述、变更详情、测试说明

---

## 技能的结构 / Skill Structure

### 1. 技能名称 / Skill Name
- 清晰的名称
- 描述技能用途

### 2. 指令 / Instructions
- 详细的执行步骤
- 输出格式要求
- 示例

### 3. 触发条件 / Trigger Conditions
- 何时使用这个技能
- 什么场景下激活

---

## 创建技能的步骤 / Steps to Create a Skill

### 第一步：定义需求 / Step 1: Define Requirements
- 确定要解决的问题
- 明确输出格式

### 第二步：编写指令 / Step 2: Write Instructions
- 清晰的步骤
- 具体的要求
- 示例演示

### 第三步：测试技能 / Step 3: Test the Skill
- 运行技能
- 检查输出
- 调整优化

### 第四步：保存和使用 / Step 4: Save and Use
- 保存技能
- 在需要时调用

---

## 技能的类型 / Types of Skills

### 1. 个人技能 / Personal Skills
- 仅自己可用
- 针对个人工作流

### 2. 项目技能 / Project Skills
- 项目范围内可用
- 团队共享

---

## 最佳实践 / Best Practices

### 1. 保持简单 / Keep It Simple
- 从简单的任务开始
- 逐步增加复杂度

### 2. 具体明确 / Be Specific
- 清晰的指令
- 具体的要求

### 3. 提供示例 / Provide Examples
- 展示期望的输出
- 帮助 Claude 理解

### 4. 测试迭代 / Test and Iterate
- 多次测试
- 根据结果调整
