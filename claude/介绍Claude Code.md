## 简介 / Introduction

Anthropic 官方介绍 Claude Code，这是一款专为开发者设计的 AI 编程助手。

---

## 什么是 Claude Code？/ What is Claude Code?

Claude Code 是 Anthropic 推出的开发者工具，旨在帮助程序员更高效地编写代码。

**核心理念：**
- 成为开发者的伙伴
- 不是替代开发者，而是增强
- 注重安全性和可控性

---

## 主要功能 / Main Features

### 1. 智能代码补全 / Smart Code Completion

**功能：**
- 上下文感知的代码建议
- 多语言支持
- 实时补全

**功能：**

**功能：**
- 静态分析

### 5. 测试生成 / Test Generation

**功能：**
- 单元测试生成

## 安装和使用 / Installation & Usage

### 安装方式
```bash
# 通过 npm 安装
npm install -g @anthropic-ai/claude-code

# 或通过 Homebrew
brew install claude-code
```

### 基本使用
```bash
# 启动 Claude Code
claude-code

# 或在项目中运行
claude-code --project .
```
