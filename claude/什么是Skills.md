## 简介 / Introduction

A skill teaches Claude how to do something once. Then, Claude then applies that knowledge automatically whenever it's relevant.

## 核心概念 / Core Concept

### 什么是 Skills（技能）？

**定义 / Definition:**
- Skills 是 Claude Code 的核心功能
- 允许用户教 Claude 如何做某事一次
- 之后 Claude 会在相关场景自动应用

**工作原理 / How It Works:**
1. 用户创建一个 skill（技能）
2. 定义技能的触发条件和行为
3. Claude 在合适场景自动使用该技能
