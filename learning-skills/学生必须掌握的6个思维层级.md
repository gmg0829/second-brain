## 简介 / Introduction

Ali Abdaal 介绍每个学生必须掌握的6个思维层次，从基础到高级。

---

## 六个思维层次 / Six Levels

### 1. 记忆 / Memorization

**层次：**
- 记住基本信息
- 事实和数据
- 基础层次

### 2. 理解 / Understanding

**层次：**
- 理解概念
- 能用自己的话解释
- 超越记忆

### 3. 应用 / Application

**层次：**
- 使用知识解决问题
- 实践操作
- 学以致用

### 4. 分析 / Analysis

**层次：**
- 分解复杂问题
- 找联系和模式
- 批判性思考

### 5. 评估 / Evaluation

**层次：**
- 判断观点优劣
- 权衡取舍
- 做出决策

### 6. 创造 / Creation

**层次：**
- 创造新事物
- 综合知识
- 最高层次

---

## 思维层次进阶 / Progression

```
记忆 → 理解 → 应用 → 分析 → 评估 → 创造
基础   初级   中级   中高级   高级   顶级
```

---

## 总结 / Summary

从记忆到创造，六个层次代表学习能力和思维深度的不断提升。
