# Lets start with Competitive Programming!

## 内容概要

这是 Gaurav Sen 频道早期的频道介绍视频，核心内容是 Gaurav 讲述自己接触竞赛编程的个人经历，以及创办这个频道的初衷。几年前，Gaurav 作为一名大学生开始接触竞赛编程，他发现一个典型的困境：虽然在校内课程里学过算法和数据结构，但从未学到如何将它们应用到实际问题中。当他第一次参加 CodeChef 编程竞赛时，面对题目完全不知所措——「我学了一堆算法和数据结构，但根本不知道该怎么用在题目里」——这就是他创办这个频道要解决的核心问题：弥合「学习算法」与「应用算法」之间的鸿沟。

Gaurav 在视频中提出了一个愿景：让这个过渡期尽可能短，使初学者能够快速从零基础成长为一个优秀的程序员。他整合了一些学习资源和解题技巧，同时也向观众发出邀请：当他提出一个话题时，他自己往往也需要先学习；在社区里互相帮助才是可持续的方式。他特别强调，当你成长为一名优秀程序员之后，希望你能回馈社区——可以出题、写博客、写技术文章，甚至制作视频教程，因为这个社区虽然庞大且充满热情，但确实缺乏系统性，新人的流失率很高。最后 Gaurav 说「这个社区非常有趣，但也相当杂乱无章」，办这个频道的目的就是让它变得更有序、更易于入门。

## 核心观点

1. **「学」与「用」的鸿沟是最大痛点** — 校内教育教会你算法知识，但从不教你如何将其应用于实际竞赛题目。
2. **过渡期应该尽可能短** — 频道的目标是压缩从零基础到优秀程序员的成长时间，让学习者快速享受竞赛的乐趣。
3. **「我」也是学习者** — Gaurav 坦诚表示，当被问到不熟悉的话题时，他自己也需要先研究，这是做频道的真实动力。
4. **社区需要回馈** — 当你成长之后，希望你帮助出题、写博客、做视频，这是一个健康的社区循环。
5. **社区虽大但缺乏系统性** — 竞赛编程社区的流失率很高，新人找不到有序的学习路径。

## 关键语录

- "I had been taught algorithms and data structures, but never how to apply them."
- "When I came to a programming contest on CodeChef, I couldn't understand what the hell the questions meant."

- "The transition period should be short enough so that you can enjoy it."
- "This community is huge and very interesting, but it's also quite haphazard. New programmers — the attrition rate is huge."
- "Once you become a really good programmer, help this community! Help it out by setting questions, writing blogs, and making videos."
