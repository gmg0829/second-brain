## 一、核心主旨一句话

> **AI 不是更快的马——汽车终于到了。**

这不只是通信革命（互联网、移动），而是**计算革命**——处理信息方式的根本转变。

## 三、Pat Grady：为什么这是 AGI

### 3.1 AI 与以往浪潮的三个不同

| 维度 | 说明 |
|------|------|
| **规模最大** | 不仅是软件，还有**服务收入**：美国法律服务市场单独就有 $400 billion，等于所有软件市场 |
| **速度最快** | 白板正在被快速填充，logo 公司正在涌现 |
| **性质不同** | 互联网/云/移动是**通信革命**（信息分发）；AI 是**计算革命**（信息处理） |

### 3.2 三次大拐点

```
2022 年 11 月   → ChatGPT 时刻：世界看见了 pre-training 的力量
约 2024 年      → 01 模型：inference time compute 的第二条 scaling law
最近           → Cloud Code / Opus 4.5/4.7：长周期 agent 的力量
```

第三次拐点和前两次之间有**不连续跳跃**。

### 3.3 这就是 AGI

> "我们不敢提出技术定义——我们是风投，我们研究的是创始人和市场。但从商业角度、从实际角度、从功能角度：如果你可以派一个 agent 去完成一项工作，它能从失败中恢复并持续到任务完成……这感觉就很像 AGI。"

### 3.4 快马 vs 汽车

| | 快马（Faster Horses） | 汽车（Cars） |
|---|---|---|
| **定义** | 让你效率提升 10-40% | 让你效率提升 **10-40 倍** |
| **影响** | 稍微改变工作方式 | **彻底改变**工作性质、组织形态 |
| **举例** | 传统 SaaS 工具 | Agentic coding、全流程自动化 |

### 3.5 MAD 战略框架

**M - Modes（模式）**：客户背（customer back）

> "在计算革命中，你应该往下看（新能力源源不断），但构建 modes 时应该**往上看客户**——因为客户的变化速度远慢于能力的变化速度。"

**A - Affordance（可供性）**：路径最少阻力

> "Cloud Code 很强大，但对普通 Fortune 500 员工 affordance 不高。机会在于：为特定客户和特定问题创建**最少阻力路径**，让使用简单到爆炸。"

**D - Diffusion（扩散差距）**：应用层的机会

> 能力创造的速度 >> 能力扩散到市场的速度。每天这个差距在变大 = 应用层公司的机会越大。

### 3.6 "没有人是安全的"

> "赛马界有句话：你不能在晴天超过 15 辆车，但雨天可以。现在基础模型正在下**瓢泼大雨**般的新能力——没有领先是安全的，但任何人也可以赢得胜利。"

## 四、Sonya Huang：Agent 时代

### 4.1 从 2022 年的失败 Agent 到今天

| 时间 | 事件 |
|------|------|
| **2022 年** | AutoGPT / Baby AGI 爆火：用 GPT-3 + tools + loop = promising 但完全失败，模型不够强 |
| **2026 年初** | Agent 突然 everywhere，而且**真的管用** |

两个 killer agent 应用：
- **Cloud Code**（面向技术人群）
- **OpenClaw**（面向普通用户，手机即可使用）

> "无论你是硬核工程师还是普通用户，任何人都可以创建 agent。"

### 4.2 Agent 的三层架构

| 组件 | 角色 | 进展 |
|------|------|------|
| **Models（大脑）** | 推理和计划能力 | 从几十分钟 → 几小时，sustain 长时间任务 |
| **Tools（手臂和腿）** | 执行动作：terminal、Slack、iMessage、web search、电脑使用 | 过去 20 年为人类构建的工具，完美迁移给 agent |
| **Harness（安全带）** | persistence 持续性：保持任务、适应、持续运行 + RL 反馈循环 | RL 正在让 agent 在各领域（工程、设计、金融）持续提升 |

### 4.3 Agent 的演进阶段

```
2023: Tab Autocomplete          → 一个人类 + 一个 AI（逐行辅助）
今天: Agentic Development       → 一个人类 + 一个 agent 团队（instruction + management）
即将: Background/Async Agents  → agent spawn 子 agent，并行处理（规模将超过当前范式）
前沿: Dark Factories            → 完全不需要人类审查，cyber security 公司已在生产中运行
```

### 4.4 Agent 演进路径

```
Helpers（在你身边做少量事）
    ↓
Interns（需要管理）
    ↓
Self-managing Interns（自我管理）
    ↓
Fully Trustworthy（可以独立 push to prod）
```

### 4.5 服务是新软件（Services is the New Software）

| 行业 | Agent 能做什么 |
|------|---------------|
| **医疗** | 检查基因组、给出个性化建议、开药、推荐临床试验 |
| **法律** | 代表你谈判合同、执行诉讼、达成和解 |
| **数学/科学** | 解决 IMO 问题、发现新超导体 |
| **消费者** | 管理收件箱、日历、财务、报税 |

### 4.6 为什么 Hiring Agents 比 Hiring Employees 更划算

| | Humans | Agents |
|---|---|---|
| **扩展性** | 难 | 无限（靠算力） |
| **维护成本** | 高（需要让员工开心） | 低 |
| **成本结构** | 工资 | Tokens（通常低于等效工资） |
| **智能度** | 今天更聪明 | 但"苦涩的教训"在持续，很快会在很多事上更聪明 |

### 4.7 即将到来的奇异世界

> "我们即将到了一个非常奇怪的点：当 agent 之间开始发生商务活动会怎样？它们能互相支付吗？当 agent 能够谈判交易条款会怎样？会有成群的 agent 来保护我们免受网络攻击或 megadan 吗？"

### 4.8 压缩的时间线

| 案例 | 成就 |
|------|------|
| Nathan（Zed） | 一个人 + Cloud Code，假期完成**3 年 moomeshot 项目** |
| Brett Taylor | **一个周末**重建 Sierra |
| Notion 团队 | **6 周**重写 800 万行代码 |

> "任何人能想象的在未来 100 年建造的东西，我们认为现在**100 天**内就可以实现。"

## 五、Konstantine Buhler：认知革命

### 5.1 工业革命 vs 认知革命

| | 工业革命（Physical） | 认知革命（Cognitive） |
|---|---|---|
| **起点** | 1700 年代：人力/动物肌肉 | 大部分人类历史：人类思考 |
| **转折** | 水力/风力 → 蒸汽机 → 内燃机 → 电动马达 | 电子计算 → 神经网络 |
| **今天** | **99%+** 的体力劳动由机器完成 | 我们在**更早的阶段**，但模式类似 |

**预测**：不久的将来，**99.9%** 的地球认知工作将由机器完成。

### 5.2 四个故事

#### 故事一：铝与电解

- 1850 年代：华盛顿纪念碑需要最珍贵的金属——**铝**（在 Tiffany 展示，100 盎司）
- 几十年后：发明电解法，铝从最珍贵变成**包裹巧克力和三明治的包装纸**，用完即扔

> "铝就是 intelligence。电解就是 artificial intelligence。价值数十年才获得的 PhD 级别技能，将变得像铝一样——用完即扔。"

#### 故事二：外星设计（Alien Design）

- 2006 年 NASA：用进化算法设计卫星天线
- 传统设计：美丽的几何对称图案
- AI 设计：**扭曲的、不直观的形态**，但效率高数倍

> "AI 时代，当 AI 设计芯片、汽车、建筑，它们看起来会大不相同。AI 不会像人类那样思考——它会有**外星设计**。"

#### 故事三：Emerging Sciences（新兴科学）

- 工业革命早期：瓦特、纽曼等工程师** tinkering**（修补），持续百年
- 120 年后：卡诺提出**热力学**——像物理学一样基础科学
- 现在 AI：数万亿神经元/ tokens，仍在 **tinkering 阶段**

> "未来几十年，会有人在这个房间里提出**和热力学一样基础的新科学**——会在高中教授，会帮助我们掌握 AI，甚至帮助我们掌握意识。"

#### 故事四：艺术理性主义的终结

- 数千年艺术史：追求写实（洞穴壁画 → 希腊陶器 → 文艺复兴）
- 摄影出现：以为绘画已死
- 人类回应：**印象派、表现主义、立体主义、neo-expressionism**

> "2500 年前，希腊哲学家普罗泰戈拉写道：人是万物的尺度。AI 可以做工作，但**只有人类的连接才能让你在乎**。"

### 5.3 永恒的关系

> "10 年后，工作将发生巨变。但今天你和身边的人建立的关系会成为你回首时最有价值的东西。这就是为什么我们在这里。"
