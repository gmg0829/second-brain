## 核心内容 / Core Content

### 1. LLM 生态系统概述 / LLM Ecosystem Overview

**主要玩家 / Major Players:**
- OpenAI (ChatGPT)
- Anthropic (Claude)
- Meta (Llama)
- Google (Gemini)
- 等等

### 2. ChatGPT 交互底层原理 / Under the Hood

**工作流程 / Workflow:**
- 用户输入 → Token 化 → 模型处理 → 生成响应 → 解 Token 化
- 理解底层原理有助于更好地使用

### 3. 基础交互示例 / Basic Interactions

**常见用途 / Common Uses:**
- 问答
- 写作辅助
- 编程帮助
- 学习辅导

### 4. 模型选择与定价 / Model Selection & Pricing

**不同层级的模型 / Different Tiers:**
- 快速/便宜模型：日常简单任务
- 慢速/昂贵模型：复杂推理任务

### 5. 思考模型 / Thinking Models

**何时使用 / When to Use:**
- 需要深度推理时使用思考模型
- 简单查询用普通模型即可

## Andrej 的使用习惯 / Andrej's Usage Habits

### 日常使用场景 / Daily Use Cases:

1. **编程 / Programming:** 使用 Cursor 进行代码编写
2. **研究 / Research:** 使用深度研究功能
3. **学习 / Learning:** 上传文档进行问答
4. **写作 / Writing:** 辅助写作和润色
5. **数据分析 / Data Analysis:** 使用 Python 解释器

### 选择模型的考量 / Model Selection Considerations:

- 任务复杂度
- 时间敏感性
- 成本因素
- 准确性要求

## 关键要点 / Key Takeaways

1. **了解你的工具** - 理解不同模型的特点和适用场景
2. **善用工具** - 充分利用各种功能提高效率
3. **成本意识** - 根据任务选择合适的模型
4. **多模态** - 利用语音、图像、视频等多模态功能
5. **实践出真知** - 多使用才能掌握最佳使用方式
