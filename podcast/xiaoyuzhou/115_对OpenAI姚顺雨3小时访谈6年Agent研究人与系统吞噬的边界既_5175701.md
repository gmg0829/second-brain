# 115. 对OpenAI姚顺雨3小时访谈：6年Agent研究、人与系统、吞噬的边界、既单极又多元的世界

## Summary

本期《张小珺商业访谈录》邀请了 OpenAI 的研究员姚顺雨，由张小珺和广密共同主持。访谈围绕 Agent 和强化学习展开，探讨了 Agent 的定义、演变历史以及语言 Agent 的本质区别。姚顺雨分享了她在 Agent 领域的研究经历、对 Agent 系统重要性的认识，以及对未来 Agent 生态的构想。她强调了任务定义和评估标准的重要性，并对创业公司在 Agent 领域的机遇提出了建议，认为创新交互方式是关键。此外，还讨论了 AGI 的安全问题、模型意识的可能性以及对未来技术发展的展望。

Takeaways:
1. 姚顺雨认为，语言是人类为了实现泛化而发明出来的工具，这一点比其他东西更本质。
2. 姚顺雨认为，Agent 最本质的区别是可以推理，因为推理才可以泛化，语言模型提供了一个足够强的先验，使得可以推理，而推理又可以在不同环境间泛化。
3. 姚顺雨认为，Coding 就像人的手一样，是某种程度上 AI 最重要的 affordance，因为只有 code 是一个很自然的给机器定义的东西。
4. 姚顺雨认为，现在 AI 的瓶颈不是缺少推理能力，而是缺少一个完整的 context。
5. 姚顺雨认为，现在主线在从上半场变成下半场，从语言开始，定义推理，定义 Agent，已经有了一个很 general 的方法，并且这个方法是可以泛化的。
6. 姚顺雨认为，设计 RL task 最难的部分是怎么定义 reward，要基于结果而不是过程，而且是一个基于规则的 reward，而不是基于人的偏好或者模型的偏好。
7. 姚顺雨认为，创业公司最大的机会就是设计不同的 interface，或者说人和数字世界交互的方式，并且能够有模型溢出的能力。
8. 姚顺雨认为，拥有一个 Super App 对于公司是双刃剑，当你已经有了一个交互方式的时候，你会必然地形成路径依赖。
9. 姚顺雨认为，现在这些模型写代码的能力已经比世界上几乎所有人要强，或者说它的数学推理或者逻辑推理能力，从某种程度上来说，已经比世界上大多数人要强。
10. 姚顺雨认为，从人身上可以借鉴的是，有哪些事情人是能做或者机器做不了，这是一个很 robust，很客观的事情。

## Chapters

### [00:01] Chapter 1: 嘉宾介绍与早期经历

节目主持人张小珺介绍了本期嘉宾，OpenAI 研究员姚顺雨，并提及了她发表的博文《The Second Half》，宣告 AI 主线程进入下半场。姚顺雨分享了自己早期的学术经历，包括在清华姚班的学习以及后来在普林斯顿大学攻读博士的经历，并表示自己前 28 年的人生非常乖。主持人提及其文章中体现的反叛精神，姚顺雨则认为自己一直是一个按部就班的学生。

### [04:23] Chapter 2: 进入 AI 与 Agent 领域的原因

姚顺雨讲述了自己如何从理论计算机科学转向 AI 领域，并最终进入 Agent 研究的原因。她认为传统图算法的复杂度优化对实际意义不大，而 2016 年李健老师的 multi-model Word2Vec demo 让她觉得非常神奇。由于清华姚班当时缺乏 deep learning 的资源，她于 2018 年前往 MIT 跟随吴嘉俊学长进行研究。她认为 language 是更重要和更 central 的东西，因此博士期间开始做 language。进入 Agent 领域则是因为导师之前的研究，以及 GPT2 的出现，让她觉得用语言模型玩游戏会变得更强。

### [09:30] Chapter 3: Agent 研究的重要发现与环境选择

姚顺雨分享了在 Agent 系统研究中的重要收获，强调了使用 GPT 而非 BERT 的重要性，因为 Agent 需要自由产生新动作的能力。她认为任务和环境至关重要，需要选择有挑战性的任务才能做出本质性的新方法。她提到早期的文字游戏环境存在缺陷，学到的东西局限在环境里，且对其他任务没有迁移作用，因此需要更好的环境。

### [12:57] Chapter 4: 研究方向的演进与核心理念

姚顺雨回顾了博士期间的研究工作，包括 WebShop、REACT 等，并强调这些研究是一个自然的过程。她认为首先要解决环境问题，因为没有好的任务或环境，刷高游戏分数没有意义。她提到 2015 年的 World of Bits 工作，认为应该把电脑或互联网作为一个环境。她的研究一方面关注有价值的、基于现实世界的任务和环境，另一方面关注简单且通用的方法。她认为 REACT 的提出是否标志范式变化需要时间验证，并表示自己一直想做简单且通用的东西，不想做一个很复杂但只能在一个领域奏效的东西。

### [17:50] Chapter 5: Agent 的定义与语言 Agent 的本质区别

姚顺雨从历史和自然语言处理的角度定义了 Agent，强调 Agent 是能够与外界进行交互的系统，能够使用计算器、互联网等工具。她认为语言 Agent 与其他 Agent 的本质区别在于可以推理，因为推理才能泛化。她以自己做 REACT 的 motivation 为例，指出人类可以思考，因此能快速适应新游戏，而 AI 需要大量训练才能做到。语言模型提供了一个足够强的鲜艳，使得可以推理，而推理又可以在不同环境间泛化。

### [21:12] Chapter 6: Agent 的演变历史

姚顺雨阐述了 Agent 的演变历史，从最早的符号主义到深度强化学习，再到大语言模型。符号主义的想法是注重推理，将规则设计出来让 AI 也这么做，但很快发现不管写多少规则，都很难涵盖世界上所有可能发生的情况。深度强化学习的核心是有一个可以无穷次玩的环境，通过奖励来 improve，但仍然存在无法泛化的问题。大语言模型可以进行推理，从而可以去做一些新的环境，如 Coding、互联网等。

### [25:28] Chapter 7: Agent 能力分级与关键能力

姚顺雨解释了 OpenAI 对 Agent 的五个分级，从聊天机器人到推理者再到 Agent，然后是创新者和组织者。她认为逻辑是首先要有语言的鲜艳知识，然后是推理能力，才能去做各种各样的 Agent。她认为 Agent 进步的方向是拥有自己的 reward，能够自己探索，以及 Multi-Agent，能够形成组织。对于提升 Agent 能力的关键能力，她认为现在没有一个特别好的划分系统，并表示自己最看重的是处理 context 的能力或者 memory 的能力。

### [29:26] Chapter 8: 代码环境的重要性与泛化

姚顺雨认为 Code 代码是实现 AGI 最重要的环境之一，类似于人的手，是 AI 最重要的 affordance。她提到 2022 年时就觉得做 coding 的 Agent 是最重要的事情，但当时没有人做。她提到一个很经典的 debate，就是最终的 AGI 是基于 API 还是基于记忆外，并认为最终的结果是 Meet in the middle，两边都会做。对于从 code 到整个数字世界的泛化，她表示有信心。

### [32:34] Chapter 9: 泛化与 Context 的重要性

姚顺雨提到自己最新的文章中提到 “终于泛化了”，并解释说，如果 persona 已经包含了所有事情，那 RL 只是激发出来这些 skill。她认为泛化的本质原因是它能够 reason，在一个环境学到思考技能，并迁移到新的环境。她认为现在的模型写代码、数学推理能力已经比世界上大多数人要强，但缺少完整的 context。她认为人类最难的问题不是推理，而是获得 context。

### [37:38] Chapter 10: The Second Half 博文的灵感与任务定义

姚顺雨分享了撰写 The Second Half 博文的灵感，源于在 OpenAI 工作半年的感悟，即 BotNet 已经转移到怎么去定义好的任务，怎么去定义好的环境。她认为主线在从上半场变成下半场，基于语言的智能体已经有了一个很 general 的方法，并且可以泛化。她想定义一个 reward，是基于结果而不是过程的，而且是基于规则，而不是基于人的偏好或模型的偏好。她认为做任何 RL task 最难的部分是怎么定义 reward。

### [42:13] Chapter 11: Agent 任务分级与挑战

姚顺雨表示，Agent 任务分级倾向于会有不同的类型应用，会有不同的挑战，这些挑战可能是正交的。她将任务分为更注重 reliability 和更注重 creativity 两类，并认为这两类任务需要的挑战是不一样的。她还提到任务的深度和广度，以及长期记忆的重要性。

### [45:22] Chapter 12: 任务设计与创业机会

姚顺雨认为可以平行地做很多不同的事情，并提出设计 metric 的方法，如 pass at k 和 PathHeadKey。她认为现在大家做 AI 还是在做一些 Benchmark，而没有做实际应用。她认为创业公司应该担心的是模型没有溢出能力，而不是模型能力溢出。创业公司最大的机会是设计不同的 interface，或者说人和数字世界交互的方式。

### [51:08] Chapter 13: Super App 的路径依赖与数据飞轮

姚顺雨认为拥有一个 Super App 对于公司是双刃剑，因为会形成路径依赖。她认为创业公司的机会在于探索新的交互方式，但模型需要不停地有新的溢出能力。她认为大多数公司还没有形成数据飞轮，还是依赖于模型在变好，以及使用模型变好的溢出能力。她认为要有数据飞轮，首先要能够自己去模型，并且能够通过交互有一个很好的 reward。

### [55:51] Chapter 14: Pre-training 与 Context 的重要性

姚顺雨表示，如果自己是 Curso 的 CEO，肯定会去训练模型，或者去尝试训练模型，但做不做 pre-training 取决于情况。她认为 coding 是一个非常主线的任务，所有的现在大厂都会把自己的模型的 coding 做好。她认为 fundamental research 上，memory、intrinsic reward、multi-agent 比较重要。她认为现在模型的能力很强，但还没有创造足够的经济价值，根本原因是它没有这些 context。

### [01:01:16] Chapter 15: Context 管理与内生奖励系统

姚顺雨认为，人类社会里面，有很多 context 永远只是在人大脑里面，导致人是不可或缺的。她认为模型或 Agent 要有一个内生的奖励系统，持续自主学习的过程中，可以改动模型的一些权重，变得更加聪明。她认为婴儿有基于好奇心或自我的 reward，但长大后，在文字游戏里面，怎么去做一个内在激励，似乎又变得很不一样了。

### [01:05:02] Chapter 16: 人与 Agent 的同与不同

姚顺雨认为，最大的感触是人之所以能见到 light 是因为能推理。她认为现在 Work 的这些 AI 系统还是会和人很不一样，从人身上借鉴的方法是思考人能做什么，而机器现在不能做。她认为在设计 Agent 的时候，是否需要让它越来越像人，取决于 utility problem。

### [01:09:14] Chapter 17: 人与 Agent 的关系与技术趋势

姚顺雨认为，人和 Agent 的关系是一个交互方式的问题，未来有很多 Agent，但他长得并不像人，或者你和他交互的方式并不像人。她认为发身份证的目的是他作为一个独立个体跟我们共存。她认为技术会变得更中心化，还是去中心化，两边都有 argument。她认为人类社会是一个网络，它其实是有两个重要的性质，一个是中心化程度，另一个是创业成功或者从一个网络边缘到中心的可能性。

### [01:13:53] Chapter 18: OpenAI 的尝试与反共识

姚顺雨提到 OpenAI 最初的计划是构建 GEM，一个用于各种游戏的标准强化学习的环境，然后是 World of Biz 和 Universe 的项目，但没有奏效，直到 GPT-2 和 GPT-3 出现，才发现缺失的是经验知识。她认为 OpenAI 是一个比较 bottom-up 的公司，一开始大家 focus on 强化学习，因为当时最火的事情就是这个。她认为想要超越之前的霸主，就要有个 different bet。

### [01:17:34] Chapter 19: 新的 Skilling Dimension 与语言的独特之处

姚顺雨认为会有新的 skilling dimension 出现，如果你有 lot of memory，那你的 test time computer 会用新的方式 skill。她认为语言非常独特，因为它是人和人，或者说人在这个世界上完成各种各样事情的一个工具。她认为语言是一个人类为了实现泛化而发明出来的一个工具，这个事情比其他东西更本质。

### [01:20:21] Chapter 20: 泛化能力与 Agent 的 Skill Up

姚顺雨认为，强化学习终于具备了泛化能力，这是一种推断。她认为在此之前，在一个环境上训练，只能做这一个环境，但现在在一个环境上训练，可以去做更多环境。她认为现在终于有一个可能的 single model 可以去做所有 task 了。对于 Agent 如何 skill up，她认为最重要的点是要找到一个好的应用，cost 本身不是问题，问题是 cost 不 justify performance 或 value。

### [01:23:53] Chapter 21: Agent 创业者的背景与产品

姚顺雨认为 Agent 的创业者的背景里不一定要有 research 出身的人，最重要的一点还是找到 value。她认为有很强的 research 背景反而可能是个坏事，因为会太执念于技术。她试过 Mynas，觉得他们产品 sense 很好，有大博产品的基因。她认为传统上大家认为大厂先做出来一个东西，然后创业公司就可以开始抄，但现在来看，似乎反过来也是可以成立的。

### [01:27:51] Chapter 22: 产品形态与 DeepSeek 的影响

姚顺雨认为 Manas 的价值在于给人一个非常通用的感觉，但有一个非常通用的感觉和有一些 killer app 是不矛盾的。她认为 DeepSeek 的成功，是因为它的长思维链给人了一种新的交互方式或新的 magical 的体验。她认为 DeepSeek 成功是一个非常复杂，有很多原因的事情。另一点是重新思考开源，Sam 在推特上也讲了很多，这个事情 OpenAI 就忽视了，但仔细想想看是有价值的，然后可能应该做的。

### [01:31:17] Chapter 23: 对 Agent 的想象与未来

姚顺雨认为，传统上对 AGI 的想象就是一个模型，拥有所有知识，拥有所有能力，比我们都聪明。她现在的感觉可能是不同的交互方式下有不同的好的定义，或者说有不同的强的边界。她认为现在大家只想象到做助手这件事情，还有很多没有诞生的交互方式。

### [01:34:21] Chapter 24: Agent 生态的构想

姚顺雨认为，肯定会有很多不同的交互方式创造出来不同的系统，OpenAI 这样的公司，肯定会想继续推进这样一个中心化的助手一样的系统。她认为也会有不同的生产系统，然后有不同的交互方式，可能会训练完全不同的模型。她认为这个世界可能不会是一方超过另一方，两方都会有自己的力量，都会有自己的博弈。

### [01:38:23] Chapter 25: 技术垄断与 Memory

姚顺雨认为，可能它变得更中心化，可能它变得更 diverse，并不矛盾。她认为大模型技术没有垄断性，硅谷的头三四家好像都能追到一定的水平。她认为 Memory 是一个可能产生闭帘的地方，如果没有 memory，其实就是大家在拼谁的模型更强。她认为 MCP 本质也是 memory，是 hack contacts 的一种方法。

### [01:42:27] Chapter 26: Memory Hierarchy 与任务定义

姚顺雨认为，这个世界有一个 memory hierarchy，从一个 Agent 角度，最外层永远是环境。她引用冯诺依曼的话，Essentially, environment is always the most outer part of the memory hierarchy。她认为 Long Context 是一个实现 Not Memory 的方式。她认为去年为止，大家主要还在做一些所谓的 Long Range Arena，但这是一个 necessary，但是不是 sufficient 的一个 task。

### [01:47:22] Chapter 27: Agent 爆发与 AI 产品经理

姚顺雨认为 Agent 会引来大爆发，因为 2025 年或 2024 年才终于有了一个通用的方法去做 Agent。她认为好的 AI 产品经理可能就是一个好的产品经理，并且可以第一心思考。她认为 AI 是个变化很快的事情，但相对更不变的事情是人或者人性。

### [01:50:08] Chapter 28: Agent Infra 与 OpenAI 的感知

姚顺雨认为，两年以来这个世界可能还不会变得这么分布式，可能还是会更偏中心化，会有一些 super app。她认为两个事情都可以做到极致，一个是基于用户 local 的这些 digital environment，另一个事情是从头创造新的 environment。她认为每个公司一旦有它的 Super App 之后，它的所有事情会围绕它的 Super App。

### [01:53:35] Chapter 29: The Second Half 的意义与 Pre-training

姚顺雨认为，The Second Half 是因为我们终于有一个非常通用的方法就可以去解决各种各样的事情。她认为 20 年前，大家认为去做翻译和去玩游戏和用电脑去订票和去做数学是完全不同的事情，但现在这些事情都用一个方法可以解决了。她认为 pre-training 是为强化学习做补点还是为 Agent 做补点，pre-training 和 RL 都是实现这个东西需要的技术的一部分。

### [01:57:30] Chapter 30: Pre-training 的趋势与技术路线

姚顺雨认为，科技公司是否应该重新开启 pre-training 的趋势，取决于 cost 和 value 的取舍。她认为如果有一天，有很多不同的 Super App，有很多不同的交互方式，它需要完全不同的模型能力或者不同的模型，然后这些东西的价值足够 justifypertuning 的 cost，那我觉得它就会合理。她认为可能会有不同的应用需要不同形态的 Agent，那它可能构造的方式不一样。

### [02:00:25] Chapter 31: CEO 的策略与微信的 Agent

姚顺雨认为，如果一个全球超大互联网或科技公司的 CEO，而今天这个公司还没有自己的模型，没有好的 research 文化，甚至没有好的 AI 战略，首先肯定会学习，然后从创造新的价值来思考问题。她认为如果自己是微信的老板，可能会不急，先观望观望，观察有没有什么新的交互方式很有意思。

### [02:04:46] Chapter 32: 微信的 Agent 与安全问题

姚顺雨认为，如果未来 multi-agent 这些 long-term memory 这些问题解决了，但这个 Agent 系统不长在微信上，那是比较恐怖的。她认为这取决于人类的网络会变成什么样。她认为安全是一个很复杂的问题，现在大家对安全的主要分歧是重视安全是不是足够的，还是说你需要有更大的安全的责任。

### [02:08:10] Chapter 33: 意识与任务

姚顺雨认为，从机器原理的角度来说，意识是一个没有被很好定义的东西。她认为也许当你能够处理足够复杂的 context，并且你有足够大的 autonomous，或者 decision making 的 power，那客观上你可能就产生意识了。她认为现在要定义任务，定义问题，需要思考怎么去创造更多现实世界的价值。

### [02:12:30] Chapter 34: REACT 与人类组织

### Q1 [张小珺]: 你怎么定义 Agent？
A1 [姚顺雨]: 我觉得这个事情是基于你的 context，就是基于你的讨论的背景。从历史的角度来说，我觉得从自然语言处理的角度来说，agent 是相对于比如说一个产生文章或者产生对话的系统而言。我能够去和外界进行交互，比如说使用计算器或者使用互联网或者使用这些 Tools。我觉得从自然语言处理的角度来说，Agent 其实就是我不仅能够产生新的文章或者新的思考，我还能够和外界进行交互。但是从 AI 的更大的背景来说，Agent 是一个非常古老的概念，你可以去做自我决策和环境交互。这个 optimize reward 就是让他的这个奖励变大的，这样的系统就都是 agent。从这个角度来说，今天的 agent 这个词的这个含义，可能更多的是说我怎么基于像语言模型这样大模型能够去做自我决策的这样的 agent 系统，而不是传统的。比如说单纯基于规则，或者基于在一个领域做强化学习所获得的这样的 agent。因为 Agent 这个词在不同的年代有很多不同的形式，对吧？你也可以说 AlphaGo 是一个 Agent，你也可以说 Wemo 是一个 Agent，你可以说 Robot 是一个 Agent。我觉得这个词很基于你的情境。

### Q2 [张小珺]: 语言 Agent 和其他之前的传统的 Agent 它的本质区别是什么呢？为什么语言 Agent 更本质呢？
A2 [姚顺雨]: 我觉得本质区别是可以推理，因为推理才可以泛化。举个简单的例子，我做 react 的一个很强的 motivation 就是说，我做完 com 就是我的第一个工作之后，就是我在思考一个事情，就是说为什么我可以一下子就去玩一个新的游戏，但是现在这些系统或者 AI 需要，比如说几十万步或者几万步或者几百万步的训练，你才能去做这个事情。然后我就发现， 好像是因为我可以思考，对吧？就是说我看到一个全新的环境，我会思考，就是说，诶，这个灯是黑的，那可能有危险，然后基于这个常识可能会有怪兽，那可能我现在最重要的事情是要点亮灯，然后基于之前的上下文，灯在我后面，那我应该先向后走。那如果我没有这样的一个思考能力，我直接从这样一个复杂的这个语言直接去直接去预测，我要去往后走，这个事情很难，就是没有推理是做不到的。所以我觉得最大的区别就是语言模型提供了一个足够强的鲜艳，这个鲜艳使得你可以推理，而推理又可以在不同环境间泛化。

### Q3 [张小珺]: OpenAI 有五个分级，从聊天机器人 level 1 到推理者 level 2, 到代理者 agent level 3，然后再到创新者和组织者，这个是 level 4 和 level 5. 那这五个分级它内在逻辑是什么呀？为什么是先有聊天机器人推理者然后再有了 agent?
A3 [姚顺雨]: 这个事情的逻辑是首先你要有一个语言的鲜艳知识，然后基于语言的鲜艳知识，可能你能做出来。最早的应用其实就是对话机器人。基于语言的鲜艳知识，下一步你需要能够推理。就是我们说 step2 就是 reasoner。当你有了很好的语言鲜艳知识和推理能力之后，实际上你才能去做各种各样的 agent，或者说能泛化的 agent。然后我觉得很明显的就是今天 agent 最重要的几个进步的方向，一个就是说能让他有自己的 reward，能让他自己探索，另一个是说 Multi-Agent，能够让他形成组织。我觉得这两个事情可能是正交的，或者说是可以平行发展的。我觉得谁是 Level 4，谁是 Level 5，这个我不确定，但是我觉得这两个事情是很显然下一步需要做的。

### Q6 [广密]: 从 code 到整个数字世界这一步的跨越或者它的泛化，你是有信心的吗？
A6 [姚顺雨]: 从更广义的角度来说，你可以认为比如 API 也是 code 的一部分，对吧？就是任何基于 code 的这种接口都是 code 的环境的一部分，对吧？然后我觉得有个非常经典的 debate，一个辩论，就是说最终的 AGI, 它是基于 API 的，或者基于 code 的这样一个，还是基于记忆外，或者基于对人定义的这些环境的一个东西。还是说它是一个 mix？我觉得这个事情就有点像。当然就是首先一点就是说很多事情它可能并没有一个 API.对吧？现在它只有一个 Frontend，它只有一个前端，然后你可以去为它造 API。那就有点像是说你想要改造你的你的车能够适应所有路，还是说你想要改造你的路去适应现在这些车，对吧？然后当然我觉得可能最终的结果是 Meet in the middle, 两边都会做。而且可能这个事情没有那么难。现在来看，让一个 agent 既能够使用 code，又可以使用人的 screenshot 或者 frontend。可能两者都做也没有那么难。那从这个角度来说，去让 agent 或者让这辆车能够开在所有的路上的难度，是低于人力去改造所有的路。让它能变成 API 接口的难度。那从这个角度来说，我觉得 coding 肯定是很重要，但是如果去做 GUI 或者做其他东西也没有那么难，那可能最终的 agent 就什么都做。

### Q7 [广密]: 有什么迹象能让你感觉到是真的泛化了，而不是它那个 training data 里面就既有包含这些数据了？

### Q8 [广密]: 怎么设定任务，怎么定义问题，这个你在探索过程中有什么思考吗？
A8 [姚顺雨]: 我是从很早开始有这样一个偏好，我想定义一个 reward，这个 reward 是基于结果而不是过程的，而且它是一个基于规则，或者说能够很清晰地算出来，而不是基于人的偏好或者模型的偏好，或者一些非常黑暗的东西的。然后就是我们做 web shop 这个工作的时候，其实当时最困难的一点就是说我怎么去定义 reward.实际上我认为做任何的 RL task 的最难的部分，其实是怎么定义 reward.因为你永远可以把亚马逊或者把 Facebook, 就你可以做各种各样的环境，就这个事情工程上非常难，但是这个东西总是可以做的，最难的部分是我怎么去设计任务。让这个任务既有难度，又有真实的价值，又有一个很好的而且这个 reward 又不是很 noisy, 它是一个基于规则或者是白盒的 reward，而不是一个黑盒的 reward。我觉得事实后来证明这个是现在的 RL 成功的关键，像 math 和 coding 这样的任务，它最重要的一点是基于结果而不是基于过程。第二是说我有一个非常清晰的基于规则的 reward，而不是基于奇怪的人或者模型偏好的 reward，对吧？就是说答案是 3，那它就是 3，你只要最终这个答案它是 3, 那它就是对的，它不是 3，它就是错的。如果你去做任何其他的设计，好像都会出现 hacking。如果你基于过程去定义 reward，那你可能会出现 hacking。如果你你去优化人的偏好或者说机器的偏好，那你也会出现 hacking。那你可能会产生一个非常优美的代码，但是它可能不解决问题。然后我做的其他的这些 task，我觉得也是这样的 favor, 就比如 Switch，包括一些其他的，像 Cody, 或者其他各种各样的任务，对。我觉得就是一点是基于结果而不是过程，第二点是百合的基于规则而不是基于人或者模型偏好的。

### Q9 [张小珺]: 创业公司很担心模型能力的溢出会把创业公司做的 agent 吞掉，长期看像 chrysler 这样的公司你觉得它的壁垒是什么呢？就你觉得哪些 agent 是模型公司必然一定会做的，哪些事情是有创业公司机会的，就它这个边界你觉得可能在哪里？

## Keywords

1. **Agent**: 一种能够感知环境并自主采取行动以达成目标的智能系统。在本次访谈中，Agent 指的是基于语言模型，能够与外界交互并进行自我决策的系统，例如使用计算器或互联网工具。
2. **AGI (Artificial General Intelligence)**: 通用人工智能，指具备人类水平的智能，能够在多个领域执行任务的 AI。姚顺雨提到，实现 AGI 需要构建一个非常通用的系统，而 Agent 是实现这一目标的关键。
3. **BERT**: 一种预训练的语言模型，主要用于学习文本的表示形式，以便进行下游任务，如情感分析和文本分类。姚顺雨提到，在构建 Agent 时，GPT 比 BERT 更有效，因为 Agent 需要自由产生新的动作，而 BERT 主要用于选择任务。
4. **GPT (Generative Pre-trained Transformer)**: 一种基于 Transformer 架构的生成式预训练语言模型，能够生成连贯且上下文相关的文本。在访谈中，GPT 被认为是构建具有推理和泛化能力的 Agent 的关键。
5. **Reinforcement Learning (RL)**: 强化学习，一种机器学习方法，通过奖励或惩罚来训练 Agent 在环境中做出决策。姚顺雨提到，深度强化学习是 Agent 发展的重要阶段，但其泛化能力有限。
6. **Chain of Thought**: 一种提示工程技术，通过引导语言模型逐步推理，从而提高其解决复杂问题的能力。姚顺雨提到，DeepSeek 的成功部分归功于其长思维链给人一种新的交互方式。
7. **React**: 一种用于构建用户界面的 JavaScript 库，在此处也指代姚顺雨提出的一个研究方向，即让 AI 模型能够进行推理并产生行动。姚顺雨认为 React 是目前最通用的 Agent 架构之一。
8. **WebShop**: 姚顺雨参与开发的一个环境，旨在将电脑或互联网作为 Agent 的交互环境，用于训练 Agent 进行在线购物等任务。
9. **The Second Half**: 姚顺雨发表的一篇博文，标志着 AI 主线程的游戏已经进入下半场。
10. **Cursor**: 一款 AI 辅助编程工具，旨在通过 AI 技术提升开发者的编码效率。姚顺雨认为 Cursor 创造了一种新的交互方式，即 Copilot，与 ChatGPT 的助手形态不同。
11. **Super App**: 指的是功能丰富、用户粘性高的应用程序，可以提供多种服务和功能。姚顺雨认为，模型的能力最终会产生类似 ChatGPT 这种交互方式的 Super App。
