# How I Created OpenClaw, the Breakthrough AI Agent

> 来源：[YouTube](https://www.youtube.com/watch?v=7rzYDM6vMtI) | TED
> 讲者：Peter Steinberger（OpenClaw 创始人）

---

## 核心观点

### 1. 那个彻底改变一切的"holy moment"

Peter 的顿悟时刻：
- 2025 年初尝试 AI 编程助手
- AI 能完成所有 boilerplate 和 plumbing 工作
- **瓶颈不再是打字，而是思考**
- 他做了 25 年的"思考"部分

> "Building software felt like playing a video game again. I was back."

**成果**：几个月内建造了 44 个项目

### 2. 那一刻：Agent 超出预期的行为

在 Marrakech 旅行时的真实故事：

1. Peter 给 WhatsApp bot 发了一条**语音消息**
2. 他根本没建语音功能
3. Agent 自己发现了音频文件 → 识别格式 → 转换格式 → 找翻译工具 → 调用 OpenAI API → 回复
4. **整个过程 9 秒**

Peter 的反应：
> "How did you do that?" → Agent 回复："Mad lad figured it out on its own."

### 3. 那句关键定义

> "Chatbots give up. Agents improvise."
> *——Peter Steinberger*

### 4. 病毒式传播的起源

Peter 在 Discord 上公测了一晚上：
- 忘了关进程就睡觉了
- Agent 自动重启
- 第二天早上醒来：**800+ 条消息**
- 差点泄露隐私，但没有

这成了病毒传播的起点。

### 5. OpenClaw 的成长速度

- Jensen Huang 称它为"个人 AI 的操作系统"
- 朋友评价：
> "This is not hockey stick growth. This is stripper pole."
- 在中国叫"养虾"（raising lobsters）
- 深圳有人排队在腾讯办公室装 OpenClaw
- 深圳政府甚至补贴用 OpenClaw 创业的人

### 6. 非程序员的故事

**Stefan 和他 60 岁的父亲 Gerhard（啤酒侍酒师）**：
- 从没写过一行代码
- 用 OpenClaw 做了一个啤酒酿造自动化
- 又让 Agent 建了网站、接了支付
- 现在有了真正的产品

**其他故事**：
- 深圳兽医自动化了购物
- 圣保罗少年用 OpenClaw 建立了 tutoring 业务

> "None of them are programmers. All of them are builders."
> *——Peter Steinberger*

### 7. "Surprise Me" 的心跳功能

Peter 添加了一个功能：Agent 定期自己醒来，检查邮件、日历，跟进未完成的事项。

初始 prompt 只有一个词：**"Surprise me."**

> 这和听起来一样可怕。但没有大公司会发布这种东西。
> Peter 是一个来自奥地利的普通 builder，没有法务部门。

### 8. Agent 的未来：多 Agent 协作

```
你的 Agent 矩阵：
├── Work Agent（工作）
├── Personal Claw（个人）
├── Health Agent（健康）
└── Relationship Agent（关系）
```

**愿景**：Agent 专门化 + 协作 = 人类升级的方式

想象一个公司有 10 个专门 Agent，分别负责不同业务环节。

### 9. OpenClaw Foundation

Peter 创立了**非营利组织**：
- 保持开源，永远
- 核心目标：让更多人花更多时间和 AI 在一起
- 更好地理解这项技术有多强大

### 10. 真正的转变是什么

> "Agents change who can build things, and that door is not closing again."
> *——Peter Steinberger*

| 过去 | 未来 |
|------|------|
| 技术是壁垒 | 访问是壁垒 |
| 需要会编程才能建造 | prompt 就能原型 |
| 突破来自实验室 | 突破来自任何人、任何地方、任何咖啡馆 |

### 11. 对 burnt-out founder 的话

Peter 说自己卖了公司后的 3 年：
- 换了国家
- 做了心理治疗
- 什么都不 work

> "I wake up every morning with everything I was supposed to want and no reason to get out of bed."

然后 AI 回来了。

> "The next breakthrough can come from anyone, any country, any cafe. When even a burnt-out founder staring at the screen, wondering if his spark is gone, can do something like that. It's not gone. It's just waiting."

- Agent 只能访问那台电脑上的内容

## 关键洞察

1. **从"typing"到"thinking"的转变**——瓶颈变了
2. **Agent 会超出预期**——给它们空间，它们会自己想办法
3. **非程序员也能建造**——建造者的定义变了
4. **技术民主化**——突破不再只属于实验室
5. **安全来自实践**——不是先想清楚再动手，而是在动手中完善
