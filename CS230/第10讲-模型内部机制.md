# Stanford CS230 第10讲：模型内部机制

## 概述

本讲探讨**神经网络可解释性**（Neural Network Interpretability），涵盖 CNN 与 Transformer 的内部机制理解方法，以及前沿大模型的诊断技术。

## 一、案例研究：2000亿参数模型的调试

当模型在推理基准测试中表现下降、安全评估失败、工具调用延迟异常时，需从以下维度排查：
- **训练与 Scaling**：损失曲线、梯度、Learning Rate、专家混合（MoE）路由
- **表示与内部状态**：注意力图、Token 嵌入
- **数据与分布**：基准污染、数据域失衡

## 二、CNN 可解释性方法

### 1. 显著性图（Saliency Map）
计算目标类别得分对输入图像的梯度，像素梯度越高（越亮），表示该像素对预测影响越大。**需使用 pre-softmax 分数**，避免其他类别干扰。

### 2. 积分梯度（Integrated Gradients）
通过生成从全黑到原始图像的插值序列，累积路径上的梯度，提供更具语义可解释性的可视化。

### 3. 遮挡敏感性（Occlusion Sensitivity）
用暗色方块逐区域遮挡输入图像，跟踪目标类别概率变化，绘制概率热力图，直观显示模型关注区域。

### 4. 类激活映射（CAM / Grad-CAM）
将全连接层替换为**全局平均池化层**，保留空间局部性。通过对最后一层特征图加权叠加，生成类激活热力图，显示模型预测依据。

### 5. 类模型可视化（Class Model Visualization）
对随机图像执行梯度上升，最大化某一类别的 pre-softmax 得分，生成模型对该类别的"mental image"（如 Dalmatians → 黑色斑点+白色背景）。

### 6. 数据集搜索（Dataset Search）
对特定滤波器的特征图，在验证集上检索激活值最高的图像，验证滤波器是否学习到有意义的模式（如边缘、纹理、形状）。

### 7. 反卷积（Deconvolution / Transposed Conv）
通过**转置卷积**反转网络：保留 max pooling 的 switch 位置、反转滤波器（上下/左右翻转）、重建激活最强的输入区域，实现从深层特征到原始输入空间的反向映射。

## 三、Transformer 可解释性

- **注意力可视化**：展示 Token 之间的关系（如代词↔名词关联），是 CNN 显著性图在语言模型中的对应物
- **嵌入可视化**：使用 t-SNE 等降维方法，验证语义相近的 Token 在向量空间中距离是否合理

> 目前对 Transformer 内部机制的理解仍非常有限，最先进的工作包括 Anthropic 的"Transformer Circuits"框架及 Induction Heads 研究。

## 四、训练与 Scaling 诊断

| 方法 | 用途 |
|------|------|
| 损失曲线监控 | 检测梯度爆炸/消失、代码 Bug |
| Scaling Laws | 判断模型大小、训练时长、数据量是否匹配（参考 Chinchilla 论文） |
| 专家混合负载监控 | 检测路由是否总是选中同一专家 |

## 五、基准测试与数据诊断

- **基准污染检测**：N-gram 匹配、语义嵌入相似度搜索；受污染的测试集需替换
- **数据域分布检查**：监控各领域（法律/代码/百科等）的损失及 Token 频率，防止某领域欠代表
- **安全评估**：对抗攻击测试、有害内容生成检测、Agent 工作流中的表现评估

## 总结

可解释性工具箱包括：**显著性图→积分梯度→遮挡敏感性→CAM→类可视化→数据集搜索→反卷积**。前沿大模型领域仍在探索阶段，Scaling Laws、损失曲线、基准与数据诊断是当前最佳实践。
