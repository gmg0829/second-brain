# Stanford CS230 第5讲 - 深度强化学习

## 核心思想

强化学习（RL）的本质是**序列决策**——让智能体（Agent）通过与环境交互，学会在每一步做出最优选择，最终实现长期收益最大化。与监督学习"通过示例学习"不同，RL强调"通过经验学习"。

## 基础概念

- **Agent（智能体）**：做出决策的主体
- **环境（Environment）**：智能体所在并与之交互的世界
- **状态（State）**：环境的当前描述；**观察（Observation）**：智能体能看到的信息（有时≠完整状态，如战争迷雾）
- **动作（Action）**：智能体在某一时刻采取的行为
- **奖励（Reward）**：环境对动作的即时反馈
- **回报（Return）**：累积折扣奖励 $R = \sum_{t} \gamma^t r_t$，折扣因子 $\gamma \in [0,1]$ 体现了"即时收益优于延迟收益"的原则

## Q-Learning

**Q表**存储"在状态 $s$ 下执行动作 $a$ 的价值"，策略为 $\pi(s) = \arg\max_a Q(s,a)$。最优Q值满足**Bellman最优方程**：

$$Q^*(s,a) = R(s,a) + \gamma \max_{a'} Q^*(s',a')$$

## 深度 Q 网络（DQN）

当状态空间巨大时（如围棋），用神经网络替代Q表——输入状态，输出各动作的Q值。训练使用**自举法（Bootstrapping）**：用当前Q网络估计目标 $Y = R + \gamma Q(s', \arg\max_{a'} Q(s',a'))$，并通过梯度下降迫使网络逼近该目标。

关键技巧：

- **Experience Replay（经验回放）**：将交互经历存入记忆库，打乱顺序采样训练，打破时间相关性，提高数据效率
- **Epsilon-Greedy 探索**：以概率 $\epsilon$ 随机探索，避免陷入局部最优

## 应用案例

| 应用 | 说明 |
|------|------|
| Atari 游戏 | DeepMind用单一DQN超越人类水平 |
| AlphaGo | 深度RL+树搜索，击败围棋世界冠军 |
| 机器人控制/自动驾驶 | 连续动作空间 |
| 推荐/广告 | 长期策略规划 |
| RLHF (ChatGPT) | 用人类偏好数据训练奖励模型，再用RL优化语言模型 |

## 探索 vs 利用（Exploration vs Exploitation）

智能体面临两难：利用已知最优策略，还是探索未知可能。$\epsilon$-\textit{greedy} 通过偶尔随机动作缓解这一问题。

## RLHF（从人类反馈中学习强化学习）

三阶段流程：

1. **SFT（监督微调）**：用人类标注的"提示-回答"对微调预训练语言模型
2. **奖励模型（Reward Model）**：用人类偏好排序数据训练独立模型，预测人类偏好
3. **RL优化**：以奖励模型为 Critic，对语言模型进行RL训练，最大化人类偏好奖励

RLHF使LLM从"续写文本"对齐为"有帮助的回答"，是GPT-2到ChatGPT跨越的关键技术。
