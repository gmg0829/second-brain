# 第4讲：对抗鲁棒性与生成模型

## 一、对抗攻击

### 1.1 三波攻击浪潮

- **2013年**：对抗样本（Adversarial Examples）—— 对图像添加微小扰动，人眼不可见但模型判断完全改变，如同神经网络的"光学幻觉"
- **后门攻击（Backdoor Attacks）**：在训练数据中植入隐藏触发器（如特定色块），使模型在看到触发器时产生错误预测
- **提示词注入（Prompt Injection）**：在文本输入中嵌入指令，绕过模型原始意图

### 1.2 对抗样本原理

**快速梯度符号法（FGSM）**：对输入 X 添加 ε × sign(∇_x J) 扰动，每像素微调方向即造成输出指数级变化。

**高维线性解释**：图像维度极高（256^768），微小扰动沿权重方向累积，导致 sigmoid 输出剧烈偏移。

### 1.3 攻击分类

| 类型 | 定义 |
|------|------|
| 白盒攻击 | 可访问模型参数 |
| 黑盒攻击 | 仅通过查询输出构建替代模型 |

### 1.4 防御手段

- **对抗训练**：将 FGSM 扰动样本及原标签加入训练集
- **输入净化**：检测异常像素分布
- **红队测试**：专门团队模拟攻击
- **RLHF**：通过人类反馈对齐模型

## 二、生成模型

### 2.1 判别 vs 生成

判别模型学习 P(Y|X)，生成模型学习 P(X) 本身，能捕捉数据潜在分布。

### 2.2 GAN（生成对抗网络）

**核心架构**：
- **生成器 G**：随机噪声 Z → 图像
- **判别器 D**：区分真实图像与生成图像

**训练目标**：minimax 博弈——G 试图欺骗 D，D 试图正确分类。

**核心问题——模式坍塌（Mode Collapse）**：G 学会欺骗 D 而非学习完整数据分布，仅生成部分样本。

**非饱和损失**：将 log(1 - D(G(Z))) 改为 -log(D(G(Z)))，避免早期梯度消失。

### 2.3 扩散模型（Diffusion Models）

**核心思想**：逐步加噪再学习去噪，单模型（非对抗）。

**前向扩散**：X_t = √(ᾱ_t) X_0 + √(1 - ᾱ_t) ε，逐步添加高斯噪声直至图像不可识别。

**反向去噪**：训练网络预测累计噪声 ε̂ ，从 X_T 逐步减去 ε̂ 恢复 X_0。

**优势**：
- 避免模式坍塌
- 单一模型，训练更稳定
- 分层噪声调度，从易到难

**潜在扩散（Latent Diffusion）**：在自动编码器压缩的潜空间而非像素空间执行扩散，大幅降低计算成本。

### 2.4 视频生成

与图像扩散相同，区别在于处理时空立方体（多帧 token），模型需保持帧间时间一致性。
